    R Reference

    Language and Syntax

    Name Package Section Description Usage Help
    <- base R Section Assigns a value to a variable. name <- value Help
    = base R Section Assigns values to named function arguments. function(argument = value) Help
    ? base R Section Opens the help page for a function or topic. ?topic Help
    == base R Section Tests whether two values are equal. x == y Help
    != base R Section Tests whether two values are not equal. x != y Help
    %in% base R Section Tests whether each value in one vector is present in another vector. x %in% table Help
    < base R Section Tests whether one value is less than another. x < y Help
    <= base R Section Tests whether one value is less than or equal to another. x <= y Help
    > base R Section Tests whether one value is greater than another. x > y Help
    >= base R Section Tests whether one value is greater than or equal to another. x >= y Help
    |> base R Section Passes the result of one step as the first argument to the next function. object |> function() Help
    for base R Section Repeats a block of code once for each value in a sequence. for (item in sequence) { ... } Help
    install.packages() base R Section Installs an R package from CRAN. This only needs to be done once for each package. install.packages("package") Help
    library() base R Section Loads an installed R package so its functions are available. library(package) Help
    function() base R Section Defines a new function. name <- function(arguments) { ... } Help
    return() base R Section Specifies the value returned by a function. return(value) Help

    Basic R functions

    Name Package Section Description Usage Help
    c() base R Section Combines values into a vector. c(...) Help
    print() base R Section Prints an object or value to the console. print(x) Help
    paste() base R Section Joins one or more values together into a single piece of text, separating them with spaces by default. paste(...) Help
    paste0() base R Section Joins values together as text without inserting spaces or other separators. paste0(...) Help
    head() utils Section Returns the first few rows of an object. head(x, n = 6) Help
    class() base R Section Returns the type (class) of an object. class(x) Help
    names() base R Section Gets or sets the names of the elements in an object. names(x) <- value Help
    cat() base R Section Prints one or more values without automatically starting a new line after each one. cat(...) Help
    rep() base R Section Repeats a value or vector a specified number of times. rep(x, times) Help
    seq() base R Section Creates a sequence of values with a specified start, end and increment. seq(from, to, by) Help
    seq_len() base R Section Creates a sequence of whole numbers from 1 to `n`. seq_len(n) Help
    as() methods Section Converts an object from one class to another. as(object, "ClassName") Help

    Data frames

    Name Package Section Description Usage Help
    as_date() lubridate Section Converts a date-time value into a date by removing the time component. as_date(x) Help
    clean_names() janitor Section Renames the columns of a data frame into a consistent format by replacing spaces and punctuation with underscores and converting text to lower case. clean_names(data) Help
    count() dplyr Section Counts the number of rows containing each distinct value or combination of values. count(data, columns) Help
    desc() dplyr Section Sorts values in descending order when used with `arrange()`. desc(x) Help
    distinct() dplyr Section Removes duplicate rows from a data frame. distinct(data) Help
    ends_with() tidyselect Section Selects columns whose names end with specified text. ends_with(text) Help
    filter() dplyr Section Selects rows that satisfy one or more conditions. filter(data, condition) Help
    full_join() dplyr Section Joins two data frames, keeping all rows from both data frames. full_join(x, y, by = ...) Help
    glimpse() dplyr Section Displays the structure of a data frame in a compact, readable format. glimpse(data) Help
    group_by() dplyr Section Groups rows of a data frame so that later calculations are carried out separately for each group. group_by(data, columns) Help
    gt() gt Section Displays a data frame as a formatted table. gt(data) Help
    inner_join() dplyr Section Joins two data frames, keeping only rows present in both. inner_join(x, y, by = ...) Help
    left_join() dplyr Section Joins two data frames, keeping all rows from the first data frame. left_join(x, y, by = ...) Help
    mutate() dplyr Section Creates new columns or modifies existing columns in a data frame. mutate(data, new_column = calculation) Help
    nrow() base R Section Counts the number of rows in a data frame nrow(data) NA
    pivot_longer() tidyr Section Converts data from wide format to long format. pivot_longer(data, ...) Help
    pull() dplyr Section Extracts a single column from a data frame as a vector. pull(data, column) Help
    rename() dplyr Section Changes the names of columns in a data frame. rename(data, new_name = old_name) Help
    right_join() dplyr Section Joins two data frames, keeping all rows from the second data frame. right_join(x, y, by = ...) Help
    select() dplyr Section Selects one or more columns from a data frame. select(data, columns) Help
    separate_wider_delim() tidyr Section Splits a text column into multiple columns using a specified delimiter. separate_wider_delim(data, column, delim, names) Help
    slice_max() dplyr Section Selects the rows with the largest values in a column. slice_max(data, order_by, n = 1) Help
    summarize() dplyr Section Calculates one or more summary statistics for each group in a data frame. summarize(data, ...) Help
    tibble() tibble Section Creates a tibble, a modern type of data frame. tibble(column = values, ...) Help
    ungroup() dplyr Section Removes grouping from a grouped data frame. ungroup(data) Help

    Name Package Section Description Usage Help
    sample() base R Section Randomly selects values from a vector. It can sample with equal or specified probabilities. sample(x, size, replace = FALSE, prob = NULL) Help
    dbinom() stats Section Calculates the probability of obtaining exactly a specified number of successes in a binomial distribution. dbinom(x, size, prob) Help
    dpois() stats Section Calculates the probability of observing exactly a specified number of events under a Poisson distribution. dpois(x, lambda) Help
    pbinom() stats Section Calculates the probability of obtaining no more than a specified number of successes in a binomial distribution. pbinom(q, size, prob) Help
    rbinom() stats Section Generates random numbers of successes from a binomial distribution. rbinom(n, size, prob) Help
    rpois() stats Section Generates random values from a Poisson distribution. rpois(n, lambda) Help
    runif() stats Section Generates random numbers from a uniform distribution. runif(n) Help
