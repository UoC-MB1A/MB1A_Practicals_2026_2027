    Statistical test recap

    Here is a reminder of some statistical tests and the data types they are appropriate for.

    Response variable Explanatory variable(s) Statistical test/model
    Continuous One categorical variable, 2 groups Two-sample t-test or one-way ANOVA
    Continuous One categorical variable, 3+ groups One-way ANOVA
    Continuous One continuous variable Linear regression
    Continuous Multiple categorical variables Multi-way ANOVA
    Continuous Multiple continuous variables Multiple linear regression
    Continuous Mixture of categorical and continuous variables Multiple linear regression / linear model
    Categorical* Categorical* Chi-squared test
    • For a chi-squared test, neither variable needs to be considered the explanatory or response variable.

    As long as there are many possible values (e.g. the values aren’t limited to 1, 2 or 3), count data (such as number of insects) can be treated as continuous when used as an explanatory variable. For the tests in this table, response variables described as continuous should usually be genuinely continuous rather than counts.

    Hypothesis testing exercises

    Now we are ready to test some hypotheses based on the POMS data.

    ExerciseExercise 1

    In your pollinators.qmd Quarto file, using the appropriate statistical tests, investigate at least three of the following questions. Try to choose questions requiring different tests.

    For each hypothesis, choose an appropriate statistical test and visualisation (a box plot, bar chart or scatter plot). Interpret the result using the relevant test statistic, degrees of freedom and p-value. Where relevant to the test used, also consider the confidence interval, effect size and proportion of variation explained by the model.

    For this exercise, assume that the underlying assumptions of the appropriate model have been met — you do not need to check or plot these. There is also no need to plot maps.

    The data you need are in the site_metadata data frame unless otherwise specified.

    1. Different countries in the UK are quite diverse in terms of habitat and climate. Test the hypothesis that country (Scotland, England or Wales; column country) is associated with whether sites are dominated by bees (family Apidae) or hoverflies (family Syrphidae) (column dominant_family, you will need to filter to include only these families).

    Count the groups for the plot.

    ggplot(country_family_counts, aes(x = country, y = n, fill = dominant_family)) +
  geom_col() +
  theme_bw()

    1. Melanostoma scalare, the chequered hoverfly, can be associated with sand dunes and undercliffs. Test the hypothesis that sites where M. scalare is present (you will need to create this column from the insect counts data frame and join it to the site metadata data frame) have a different mean distance from the coast (column distance_to_coast) from sites where it is absent. Does the direction of the observed difference agree with the biological prediction?
    AnswerAnswer

    Add a column showing the presence or absence of M. scalare to the site metadata data frame.

    ms_present <- insect_counts |>
  filter(species == "Melanostoma scalare") |>
  mutate(detected = n_observed > 0) |>
  left_join(site_metadata)
    Joining with `by = join_by(x1km_square)`

    Plot the distribution of distance from the coast according to the presence or absence of M. scalare.

  aes(
    x = detected,
    y = distance_to_coast,
    fill = detected
  )
) +
  geom_boxplot() +
  theme_bw()

    ms_coast_test <- t.test(
  distance_to_coast ~ detected,

  var.equal = TRUE

    Remember to save your progress regularly by committing your changes with Git.

    1. Save your changes to the files above in RStudio with the Save button.
    2. Render any Quarto documents with the Render button.
    3. Open the Git tab in RStudio.
    4. Tick the files listed above, don’t worry about any others.
    5. Click Commit and write a short message in the Commit message describing your changes, something like e.g. “Practical 1 part 1” is sufficient, then click Commit. Close the Commit popup.
