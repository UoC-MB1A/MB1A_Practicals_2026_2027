    The dataset

    The dataset we will use in this practical is pan-trap survey data from the UK Pollinator Monitoring Scheme. In this scheme, multiple pan-traps are set in each of a set of specific 1km squares across the UK. On four days each summer, volunteers will set out traps for six hours, then send the insects to be counted. Flowering plants within a 2m radius of the trap are also recorded.

    The data from the scheme is provided as data per trap, for this practical we have amalgamated the data across all dates and across each 1km square. The preprocessing of the data is described in XXXX.

    You have been provided with four data files:

    • In the insect counts CSV file - data/insect_counts.csv each row represents a combination of an insect species and a sampling site, and the total number of times that insect was observed at that site. Many of the counts will be zero.

    • In the flower counts CSV file - data/flower_counts.csv each row reprsents a combination of a flower species and a sampling site, plus TRUE or FALSE depending if that flower was ever observed within 2m of the site.

    • In the site metadata CSV file - data/site_metadata.csv, each row represents a single 1km square sampling site. The data frame contains information about the geographical location, plus land use and climate at the sample site. Additional climate data has been added based WorldClim data, which has detailed climate data by square averaged from 1970-2000. Various additional statistics have been calculated based on the information in the original data frame.

    • In the insect metadata CSV file - data/insect_metadata.csv, each row represents a single species of bee or hoverfly and its common name (where available), order and family. Additional data about the mass and length of the insects has been added from the pollimetry R package.

    • In the flower metadata CSV file - data/flower_metadata.csv, each row represents a single species of plant and its common name (where available), order and family.

    Estimators

    Let’s concentrate on a single aspect of the data for now - the species richness, measured as the number of unique species.

    Across the whole dataset, we know the total number of unique species - we have one species for each row in our insect metadata data frame.

    n_unique_species <- nrow(insect_metadata)
print(n_unique_species)
    [1] 255

    There are 255 unique species.

    The data we have here is only a sample of the whole population, but for this exercise, we will treat the complete dataset as a pseudo-population and explore what happens when we take samples from this population.

    Let’s say we wanted to estimate the total species richness across the full data set based on 20 sites and we have three possible estimators:

    • Observed richness - total number of unique species across 20 sites
    • Scaled observed richness - total number of unique species across 20 sites * (total number of sites / 20)
    • The Chao1 richness estimator, which uses the number of rare species in the sample to estimate how many species may have gone undetected.

    First let’s take a sample of 20 random sites.

    random_sites <- site_metadata |>
  distinct(x1km_square) |>
  slice_sample(n = 20) |>
  pull(x1km_square)

    Now we can extract these rows from our insect counts data frame. For this part of the practical, we’re not interested in insects with a count of 0.

    insect_sample <- insect_counts |>
  filter(
    x1km_square %in% random_sites,
    n_observed != 0
  )

gt(head(insect_sample))
    x1km_square species n_observed genus
    NC0429 Episyrphus balteatus 1 Episyrphus
    NC0429 Melanogaster hirtella 2 Melanogaster
    NC0429 Syrphus ribesii 1 Syrphus
    NC0429 Syrphus torvus 1 Syrphus
    NC0429 Syrphus vitripennis 1 Syrphus
    NC0429 Xylota segnis 1 Xylota

    Observed richness

    The observed richness is just the total number of unique species observed across all sites.

    obs_rich <- insect_sample |>
  distinct(species) |>
  pull(species)
n_obs_rich <- length(obs_rich)
print(n_obs_rich)
    [1] 183

    The observed richness estimator for this sample is 183.

    Scaled observed richness

    The scaled observed richness is the total number of unique species observed across all sites, multiplied by (total number of sites / number of sites in sample).

    n_sites_sample <- 20
scaled_obs_rich <- n_obs_rich * (site_count / n_sites_sample)
print(scaled_obs_rich)
    [1] 695.4

    The scaled observed richness estimator for this sample is 695.

    Chao1 estimator

    The Chao1 estimator estimates unseen species based on the number of species represented only once or twice in your sample.

    \[ \hat{S}_{Chao1} = S_{obs} + \frac{f_1^2}{2f_2} \]

    where:

    • \(S_{obs}\) is the number of species observed in the sample.
    • \(f_1\) is the number of species observed exactly once (singletons).
    • \(f_2\) is the number of species observed exactly twice (doubletons).
    Note

    You do not need to remember this - it is just an example of an estimator.

    obs_per_insect <- insect_sample |>
  group_by(species) |>
  summarise(n_total = sum(n_observed))

once <- obs_per_insect |> filter(n_total == 1)
twice <- obs_per_insect |> filter(n_total == 2)

n_once <- nrow(once)
n_twice <- nrow(twice)

chao <- n_obs_rich + ((n_once^2) / (2 * n_twice))
print(chao)
    [1] 215.3269

    The chao1 estimator for this sample is 215.

    None of these did a particularly good job of finding our real value of 255.

    However, you can’t measure how good an estimator is based on a single sample. Let’s try simulation and generate multiple samples.

    Remember (from the lectures): An unbiased estimator gives the correct value on average across repeated samples. The efficiency of an estimator is determined by its variance: estimators with lower variance give more consistent estimates. Mean square error (MSE) combines bias and variance and measures how far, overall, estimates tend to be from the true value.

    Using a for loop, with 10,000 iterations (this might take a minute or two to run).

    • Take a sample of 20 sites, then extract the insect counts for these sites from the data frame.
    • Calculate observed richness, scaled observed richness and chao1 for each sample.
    • Store the results for each estimator in a separate vector.
    • Combine these into a data frame.
    • For each estimator:
      • Calculate the bias, as the difference between the mean value across samples and the real value from our pseudo population.
      • Calculate the variance.
      • Calculate the mean square error.
    • Which estimator would you use, if any?
    AnswerAnswer

    Take a sample of 20 sites, then extract the insect counts for these sites from the data frame.

    Calculate observed richness, scaled observed richness and chao1 for each sample.

    Store the results for each estimator in a separate vector.

    obs_rich_vec <- c()
scaled_obs_rich_vec <- c()
chao_vec <- c()

# Loop for 10,000 iterations
for (i in seq_len(10000)) {
  # Sample 20 sites
  random_sites <- site_metadata |>
    distinct(x1km_square) |>
    slice_sample(n = 20) |>
    pull(x1km_square)

  # Extract the insect counts for these sites
  insect_sample <- insect_counts |>
    filter(
      x1km_square %in% random_sites,
      n_observed != 0
    )

  # Calculate observed richness
  obs_rich <- insect_sample |>
    distinct(species) |>
    pull(species)
  n_obs_rich <- length(obs_rich)
  # Store
  obs_rich_vec <- c(obs_rich_vec, n_obs_rich)

  # Calculate the scaled observed richness
  scaled_obs_rich <- n_obs_rich * (site_count / 20)
  # Store
  scaled_obs_rich_vec <- c(scaled_obs_rich_vec, scaled_obs_rich)

  # Calculate Chao1
  obs_per_insect <- insect_sample |>
    group_by(species) |>
    summarise(n_total = sum(n_observed))

  once <- obs_per_insect |> filter(n_total == 1)
  twice <- obs_per_insect |> filter(n_total == 2)

  n_once <- nrow(once)
  n_twice <- nrow(twice)

  chao <- n_obs_rich + ((n_once^2) / (2 * n_twice))
  # Store
  chao_vec <- c(chao_vec, chao)
}

    Combine these into a data frame.

    estimator_df <- tibble(
  Observed = obs_rich_vec,
  Scaled_Observed = scaled_obs_rich_vec,
  Chao1 = chao_vec)

    For each estimator:

    Calculate the bias

    Calculate the efficiency

    Calculate the mean square error.

    estimator_summary <- estimator_df |>
  summarise(
    Bias_Observed = mean(Observed) - n_unique_species,
    Bias_Scaled_Observed = mean(Scaled_Observed) - n_unique_species,

    MSE_Scaled_Observed =mean((Scaled_Observed - n_unique_species)^2),

  )

    Which estimator would you use, if any?

    Of the three, the Chao1 estimator has the lowest mean square error, however it is still has a negative bias and a low efficiency.

    Plotting our simulated estimators also provides a lot of information.

    We can combine all three estimators into a single plot, first we need to convert the data from wide to long format (see Long and wide formats).

    The function everything() tells R to pivot all of the columns in the table. A new column, estimator will be created to specify if each row is an observed, scaled observed or chao1 estimator.

    estimator_long <- estimator_df |>
  pivot_longer(
    everything(),
    names_to = "estimator",
    values_to = "estimate"
  )

gt(head(estimator_long))
    estimator estimate
    Observed 163.0000
    Scaled_Observed 619.4000
    Chao1 195.4000
    Observed 173.0000
    Scaled_Observed 657.4000
    Chao1 199.3269

    Now, let’s plot the values of each estimator as histograms.

    The function facet_wrap() splits the data from a single data frame into multiple plots, based on the values in a categorical column. The first argument should be the variable you would like to facet by, preceded by a ~ symbol. The argument scales = "free" means that each plot can have a different scale bar - by default they are all the same.

    The function geom_vline() adds a vertical line at a specific point, specified by the argument xintercept. In this case, the line is at our pseudo-population total species richness.

    ggplot(estimator_long, aes(x = estimate)) +
  geom_histogram(bins=50) +
  facet_wrap(~ estimator, scales = "free") +
  geom_vline(xintercept = n_unique_species, color='red')

    Here it is clear again that none of these are great estimators, but that Chao1 is probably the best.

    Note

    Sometimes an estimator is bad because the sample size is too small, sometimes it’s just bad. Let’s try taking 50 sites per sample, instead of 20.

    The code below is identical to the above except for samples of 50 sites.

    obs_rich_vec_50 <- c()
scaled_obs_rich_vec_50 <- c()
chao_vec_50 <- c()

# Loop for 10,000 iterations
for (i in seq_len(10000)) {
  # Sample 50 sites
  random_sites <- site_metadata |>
    distinct(x1km_square) |>
    slice_sample(n = 50) |>
    pull(x1km_square)

  # Extract the insect counts for these sites
  insect_sample <- insect_counts |>
    filter(
      x1km_square %in% random_sites,
      n_observed != 0
    )

  # Calculate observed richness
  obs_rich <- insect_sample |>
    distinct(species) |>
    pull(species)
  n_obs_rich <- length(obs_rich)
  # Store
  obs_rich_vec_50 <- c(obs_rich_vec_50, n_obs_rich)

  # Calculate the scaled observed richness
  scaled_obs_rich <- n_obs_rich * (site_count / 50)
  # Store
  scaled_obs_rich_vec_50 <- c(scaled_obs_rich_vec_50, scaled_obs_rich)

  # Calculate Chao1
  obs_per_insect <- insect_sample |>
    group_by(species) |>
