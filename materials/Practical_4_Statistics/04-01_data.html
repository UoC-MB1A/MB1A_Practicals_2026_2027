    Pollinator dataset

    Core

    We will use this research dataset repeatedly throughout both this practical and Practical 6 (Further Statistics) and visit others as needed.

    The main dataset we will use in this practical is pan-trap survey data from the UK Pollinator Monitoring Scheme (PoMS). In this scheme, multiple pan-traps are set in each of a set of specific 1km squares across the UK. On four days each summer, volunteers will set out traps for six hours, then send the insects to be counted. Flowering plants within a 2m radius of the trap are also recorded.

    The data from the scheme is provided as data per trap, for this practical we have amalgamated the data across all dates and across each 1km square. The preprocessing of the data is described in XXXX.

    You have been provided with three data files:

    • In the insect counts CSV file - data/insect_counts.csv each row represents a combination of an insect species and a sampling site, and the total number of times that insect was observed at that site. Many of the counts will be zero.

    • In the flower counts CSV file - data/flower_counts.csv each row represents a combination of a flower species and a sampling site, plus TRUE or FALSE depending if that flower was ever observed within 2m of the site.

    • In the site metadata CSV file - data/site_metadata.csv, each row represents a single 1km square sampling site. The data frame contains information about the geographical location, plus land use and climate at the sample site. Additional climate data has been added based on WorldClim data, which has detailed climate data by square averaged from 1970-2000. Various additional statistics have been calculated based on the information in the original data frame.

    Data citation

    UK Pollinator Monitoring Scheme (2024). 1km square pan trap data from the UK Pollinator Monitoring Scheme, 2017-2021. NERC EDS Environmental Information Data Centre. (Dataset).

    The UK Pollinator Monitoring Scheme (PoMS) is a partnership funded jointly by UKCEH and JNCC (through funding from Defra, Scottish Government, Welsh Government, and DAERA). UKCEH’s contribution is funded by the Natural Environment Research Council award number NE/R016429/1 as part of the UK-SCAPE programme delivering National Capability. Between 2017 and 2021, PoMS was funded by UKCEH and Defra (England), Welsh Government, Scottish Government, DAERA (Northern Ireland), and JNCC. PoMS is indebted to the many volunteers who carry out surveys and contribute data to the scheme.

    ExerciseExercise 1 - Revise data frame operations

    Recommended

    In your pollinators.qmd Quarto file:

    • Read the three CSV files:

      • data/insect_counts.csv
      • data/flower_counts.csv
      • data/site_metadata.csv

    • Count how many unique sites there are. Site ID is in the x1km_square column of the insect counts data frame and site metadata data frame.

    • Count how many observations of insects there are - including multiple observations of the same insect at the same site. Number of observations is in the n_observed column of the insect counts data frame.

    • Find the insect species which was observed most frequently and how many times it was observed. Insect species is in the column species of the insect counts data frame.

    AnswerAnswer

    Read the three CSV files

    insect_counts <- read_csv("data/insect_counts.csv")
flower_counts <- read_csv("data/flower_counts.csv")
site_metadata <- read_csv("data/site_metadata.csv")

    Count how many unique sites there are. Site ID is in the x1km_square column of the insect counts data frame and site metadata data frame.

    site_count <- nrow(site_metadata)
print(site_count)
    [1] 76

    There are 76 sites.

    Count how many observations of insects there are - including multiple observations of the same insect at the same site. Number of observations is in the n_observed column of the insect counts data frame

    total_insect_obs <- insect_counts |>
  pull(n_observed) |>
  sum()
print(total_insect_obs)
    [1] 15126

    There are 15126 insect observations.

    Find the insect species which was observed most frequently and how many times it was observed. Insect species is in the column species of the insect counts data frame.

    insect_totals <- insect_counts |>
  group_by(species) |>
  summarise(n_obs = sum(n_observed))

insect_totals <- insect_totals |>
  arrange(desc(n_obs))

gt(head(insect_totals))
    species n_obs
    Episyrphus balteatus 1034
    Apis mellifera 744
    Bombus lucorum 705
    Syrphus ribesii 625
    Helophilus pendulus 538
    Lasioglossum calceatum 490

    The most commonly observed species was Episyrphus balteatus, which was observed 1034 times.
