    Pollinator dataset

    Core

    We will use this research dataset repeatedly throughout both this practical and Practical 6 (Further Statistics) and visit others as needed.

    The main dataset we will use in this practical is pan-trap survey data from the UK Pollinator Monitoring Scheme (PoMS). In this scheme, multiple pan-traps are set in each of a set of specific 1km squares across the UK. On four days each summer, volunteers will set out traps for six hours, then send the insects to be counted. Flowering plants within a 2m radius of the trap are also recorded.

    The data from the scheme is provided as data per trap, for this practical we have amalgamated the data across all dates and across each 1km square.

    You have been provided with three data files:

    • In the insect counts CSV file - data/insect_counts.csv each row represents a combination of an insect species and a sampling site, and the total number of times that insect was observed at that site. Many of the counts will be zero.

    • In the flower counts CSV file - data/flower_counts.csv each row represents a combination of a flower species and a sampling site, plus TRUE or FALSE depending if that flower was ever observed within 2m of the site.

    • In the site metadata CSV file - data/site_metadata.csv, each row represents a single 1km square sampling site. The data frame contains information about the geographical location, plus land use and climate at the sample site. Additional climate data has been added based on WorldClim data, which has detailed climate data by square averaged from 1970-2000. Various additional statistics have been calculated based on the information in the original data frame.

    Data citation

    UK Pollinator Monitoring Scheme (2024). 1km square pan trap data from the UK Pollinator Monitoring Scheme, 2017-2021. NERC EDS Environmental Information Data Centre. (Dataset).

    The UK Pollinator Monitoring Scheme (PoMS) is a partnership funded jointly by UKCEH and JNCC (through funding from Defra, Scottish Government, Welsh Government, and DAERA). Between 2017 and 2021, PoMS was funded by UKCEH and Defra (England), Welsh Government, Scottish Government, DAERA (Northern Ireland), and JNCC. PoMS is indebted to the many volunteers who carry out surveys and contribute data to the scheme.

    The arrange() function sorts the rows of a data frame based on the values in a column. By default, values are arranged from smallest to largest, or from A to Z.

    ppg <- tibble(
  name = c("Blossom", "Buttercup", "Bubbles"),
  height = c(60, 62, 58)
)

gt(ppg)
    name height
    Blossom 60
    Buttercup 62
    Bubbles 58 
    by_height <- ppg |>
  arrange(height)
gt(by_height)
    name height
    Bubbles 58
    Blossom 60
    Buttercup 62

    To arrange the values from largest to smallest, or Z to A, we can use the desc() function inside arrange().

    by_height_r <- ppg |>
  arrange(desc(height))
gt(by_height_r)
    name height
    Buttercup 62
    Blossom 60
    Bubbles 58

    Examining data

    Core

    For now, let’s concentrate on a single species, the “bronze furrow bee” Halictus tumulorum. This is a relatively common bee species in the UK. It is a species of sweat bee, named because they are often attracted to sweat (although the UK ones usually aren’t).

    We can built hypotheses about the relationship between different variables and the presence or absence of H. tumulorum at each site. To do this, we need a data frame with a column which shows if H. tumulorum is present or absent at each site.

    H. tumulorum tend to be found towards the south of the UK. Let’s use our data to explore the possibility that this is because they don’t like very cold temperatures.

    We have a column in our site metadata data frame which can help us establish if this is true - the min_temp_coldest_month column. This is a BIOCLIM climate variable describing the lowest temperature in the coldest month in the map square and is the mean from 1970-2000. Technically, the lowest tempeature in the coldest month might not be the overall lowest temperature, however, for brevity from here forward we will refer to this just as minimum temperature.

    We can compare this minimum temperature for the sites where the bees are present and absent using a box plot.

    For clarity, let’s select only the relevant columns in our data frame, using the select() function.

    ExerciseExercise 3 - Box plot

    Recommended

    In your pollinators.qmd Quarto document, plot a box plot showing the value of min_temp_coldest_month in your ht_df data frame for the regions with and without these bees (i.e. based on the detected column).

    • The R function geom_boxplot() draws a box plot.
    • The aes function for this type of plot requires a categorical x variable and a continuous y variable as arguments - so you would use the arguments x = detected and y = min_temp_coldest_month.
    AnswerAnswer 
    ggplot(
  ht_df,
  aes(x = detected, y = min_temp_coldest_month, fill = detected)
) +
  geom_boxplot() +
  ggtitle("Minimum Temperature with and without H. tumulorum - Observed") +

  theme_minimal()
