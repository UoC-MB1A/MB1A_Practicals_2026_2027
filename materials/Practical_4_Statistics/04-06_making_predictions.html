    TipLearning objectives

    By the end of this part of the practical you will be able to: * Use a fitted statistical model to predict the expected value of a response variable. * Explain how a statistical model describes a probability distribution for the response variable.

    Predictions

    So far, we have mainly used linear models for hypothesis testing: to ask whether there is evidence that an explanatory variable is associated with a response variable.

    However, a fitted model can also be used to predict the expected value of the response variable for particular values of the explanatory variables.

    For example, we have already evidence that minimum temperature differs between sites where H. tumulorum is present and sites where it is absent.

    Therefore, can we use the presence of H. tumulorum to predict minimum temperature?

    First, let’s read our data frame showing presence or absence of H. tumulorum.

    Now we can fit the linear model.

    ht_lm <- lm(
  min_temp_coldest_month ~ detected,
  data = ht_df,
)

    The R function predict() can be used to predict the mean value of the response variable under a fitted linear model given a specific value of the explanatory variable.

    Let’s predict minimum temperature for sites where H. tumulorum is present.

    new_expl <- tibble(detected = TRUE)

pred <- predict(
  ht_lm,
  newdata = new_expl,
  interval = "confidence"
)

print(pred)
           fit      lwr    upr
1 1.374796 1.068391 1.6812

    The values in the fit column are the predicted minimum temperature with H. tumulorum present, and lwr (lower) and upr (upper) are the lower and upper confidence interval of the prediction.

    We can extract the standard deviation from the model (using the function sigma()) and plot the predicted distribution. This linear model assumes that observations are normally distributed around the expected value, with a common residual standard deviation

    pred_ht <- rnorm(1000, pred[1, "fit"], sigma(ht_lm))

df_ht <- tibble(data = pred_ht)

ggplot(
  df_ht,
  aes(x = data)
) +
  geom_histogram(bins = 30) +
  theme_bw()

    The model therefore gives us more than a single predicted value. For each value of the explanatory variable, it estimates the mean of a probability distribution for the response variable. For a linear model, observations are assumed to be normally distributed around this mean, with the residual standard deviation estimated by sigma().

    You can make predictions using a linear model with a continuous explanatory variable by using predict() in exactly the same way. If there are multiple explanatory variables, the value of each variable needs to be passed to the model, the process is otherwise identical.
