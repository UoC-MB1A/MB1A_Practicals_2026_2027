    For Loops

    A loop is a way of repeating a task multiple times in a computer program.

    There are two main types of loop, a for loop, which runs once for every item in a vector (or other sequence), or a while loop which runs until a certain condition is met.

    In this part of the practical we will focus on for loops, which perform a task a fixed number of times.

    We usually loop over a vector, meaning we perform the task once for each item in the vector.

    To repeat a task n times, we can use seq_len(n). This creates a sequence from 1 to n. The loop then runs n times, once for each number in this sequence. If we run our loop as for (i in seq_len(n)), each time we pass through the loop, the value of i increases by one.

    We refer to each pass through the loop as an iteration - we iterate over a loop.

    In a loop, like in a function, we use curly brackets {} to show which code is part of the loop - so everything inside the brackets will be repeated every time we iterate through the loop.

    For example:

    for (i in seq_len(10)) {
  print(i)
}

    We can add steps to our loop to run on each iteration.

    for (i in seq_len(10)) {
  # add 2 to i
  j <- i + 2
  # take the square root of j
  sj <- sqrt(j)
  # round sj to the nearest whole number
  rsj <- round(sj)
  # print rsj
  print(rsj)
}

[1] 2
[1] 3
[1] 3
[1] 3
[1] 3

    We also don’t have to actually use our variable i inside the loop, we can just use it to set the number of iterations.

    Storing results from loops

    We sometimes want to store the results of running our loop in a vector or data frame.

    For example, here we store all of the cubed numbers from our example above in a vector called cubed_nums. Before we start the loop, we create an empty vector using c(). Then, each time we pass through the loop, we use c() again to append the new result to the end of the vector. Once the loop has finished, cubed_nums contains the results from every iteration.

    cubed_nums <- c()

for (i in seq_len(20)) {
  res <- i^3
  cubed_nums <- c(cubed_nums, res)
}

print(cubed_nums)
     [1]    1    8   27   64  125  216  343  512  729 1000 1331 1728 2197 2744 3375
[16] 4096 4913 5832 6859 8000

    We can also store the results of each iteration of a loop in a data frame. One way to do this is to create an empty data frame before starting the loop using tibble(). During each iteration, we create a new one-row data frame containing the results from that iteration, then add it to the results data frame using bind_rows().

    Each time the loop runs, current_row is replaced with the results for the current species, while species_df grows by one row.

    For example, we can adapt our animal loop above to store both the species name and whether it starts with “s”:

    species <- c("monkey", "shark", "turkey", "snowman")
species_df <- tibble()

for (spp in species) {
  has_s <- startsWith(spp, "s")
  
  
  current_row <- tibble(Species=spp,
                        Starts_with_S = has_s)
  species_df <- species_df |> bind_rows(current_row)
}
gt(species_df)
    Species Starts_with_S
    monkey FALSE
    shark TRUE
    turkey FALSE
    snowman TRUE

    NoteProgramming summary
    • A for loop repeats a task a fixed number of times.
    • Each cycle through a loop is called an iteration.
    • You usually use a vector to determine the iterations of the loop.
    • You can store the results of your loop by adding to a vector in each iteration.
    • You can also store the results by adding a new row to a data frame in each iteration using bind_rows().
