    TipLearning Objectives

    By the end of this section, you will be able to: * Work with both discrete and continuous probability distributions. * Use R functions to generate random values and calculate probabilities or probability densities. * Compare observed data with theoretical probability distributions. * Use simulation to investigate whether observed data are consistent with a distribution

    Other distributions

    In part 2, you used:

    • dbinom() calculates probabilities from a binomial distribution.
    • rbinom() generates random values from a binomial distribution.
    • pbinom() calculates cumulative probabilities from a binomial distribution.

    Another function, qbinom(), calculates quantiles, allowing you to determine the value below which a given proportion of observations would be expected to fall.

    Helpfully, R uses a consistent naming convention for functions related to probability distributions. The table below shows some of the most commonly used distributions and the functions used to generate random values, calculate probabilities (or densities), calculate cumulative probabilities and calculate quantiles. The arguments differ depending on the parameters of the distribution.

    For example:

    Distribution Random samples Probability / Density Cumulative probability Quantiles
    Binomial rbinom() dbinom() pbinom() qbinom()
    Poisson rpois() dpois() ppois() qpois()
    Normal rnorm() dnorm() pnorm() qnorm()
    Exponential rexp() dexp() pexp() qexp()
    Geometric rgeom() dgeom() pgeom() qgeom()
    Hypergeometric rhyper() dhyper() phyper() qhyper()
    Negative binomial rnbinom() dnbinom() pnbinom() qnbinom()
    Uniform runif() dunif() punif() qunif()
    Gamma rgamma() dgamma() pgamma() qgamma()
    Beta rbeta() dbeta() pbeta() qbeta()
    Log-normal rlnorm() dlnorm() plnorm() qlnorm()
    Chi-squared rchisq() dchisq() pchisq() qchisq()
    Student’s t rt() dt() pt() qt()
    F rf() df() pf() qf()

    This means we can use a lot of what we’ve learned already with many different probability distributions.

    Comparing real, simulated and expected data - discrete distributions

    We can use these functions to help establish the distribution of real datasets.

    First, let’s look at some real data which is described as Poisson distributed. This data comes from a paper by Assaf et al. published in Genome Research in 2017.

    In this paper, the authors performed a mutation accumulation experiment in the fruit fly, Drosophila melanogaster. They allowed 17 populations of Drosophila to accumulate mutations for 36-53 generations, then sequenced them and counted novel mutations per population.

    The authors describe the mutation counts on each chromosome arm per population as Poisson distributed (shown in Figure 1B in the paper).

    This seems reasonable:

    • We are counting how many times an event - a mutation - occurs.
    • Counts are made over a known interval - in this case a defined number of generations.
    • Events occur independently (we assume).
    • Events occur at a constant average rate throughout the interval (again, we assume).
    • The chance of multiple events in a very small interval is negligible.
    • There is no fixed upper limit to the count - in theory any number of mutations could occur.

    In this practical, we will just look at data from one chromosome arm, the right arm of chromosome 2.

    Examining the data

    The variance is a bit higher than the mean - maybe the data is not Poisson distributed? We can do some more analysis to find out.

    Plotting the data

    Let’s plot a bar chart of our mutation counts and have a look at its distribution.

    We can plot the number of occurrences of each value of discrete variable in R by adding a geom_bar layer to our ggplot. The mapping function aes() for geom_bar only needs one argument, the column to map to the x axis. The y axis will be generated automatically by counting the number of times each value of x occurs.

    ExerciseExercise 2

    In your drosophila.qmd Quarto file, plot a bar chart of the number of populations in which each number of mutations was observed, using ggplot() and geom_bar().

    AnswerAnswer 
    ## fill="skyblue", and theme_bw are not essential, just aesthetic
ggplot(dcounts, aes(x = Novel_Mutation_Count)) +
  geom_bar(fill = "skyblue") +
  theme_bw()

    Again, this kind of looks Poisson distributed, but it’s hard to be sure.

    NoteExtension content: Adding a theoretical distribution

    It might help to compare this data to a theoretical, perfect, Poisson distribution.

    You have seen the probability mass function for the Poisson distribution in the lectures.

    \[ P(X = k) = \frac{\lambda^k e^{-\lambda}}{k!} \]

    So, to calculate the probability of observing exactly k mutations under a Poisson distribution, we have one parameter:

    • λ (lambda) - in our case, the mean number of mutations on chromosome arm 2R per population.

    k is the particular mutation count for which we want to calculate the probability.

    We can calculate this using the R function dpois.

    Let’s look at our summary data frame again:

    gt(dros_summary)
    total_nm max_nm mean_nm variance_nm
    97 11 5.705882 7.720588

    We have a mean of 5.71 mutations per population. As an example, let’s calculate the probability of observing 4 mutations. In this case, lambda = 5.71 and k = 4.

    sample_mean <- dros_summary |> pull(mean_nm)
k <- 4
prob <- dpois(x = k, lambda = sample_mean)
print(prob)
    [1] 0.1469085

    The probability is around 0.15. We can multiply this by the number of populations, 17, to get the expected number of populations which will have 4 mutations.

    n_populations <- nrow(dcounts)
expected_count <- prob * n_populations
print(expected_count)
    [1] 2.497444

    So, on chromosome 2R, if the data were perfectly Poisson distributed, we would expect to see 4 mutations in 2.5 populations (The expected count does not need to be a whole number. It represents the average number of populations we would expect across many repetitions of the experiment).

    Now let’s calculate the probability of all possible mutation counts - all possible values of k. The least possible mutations is 0, let’s use the maximum observed number of mutations as our maximum, so our theoretical distribution covers our observed range. We have this in our summary table above - the highest novel mutation count in any population is 11.

    Helpfully, we can apply dpois to multiple values of k at once, e.g. to calculate the theoretical number of populations with each mutation count - each value of k - from 0 to 11, we can do the following.

    max_k <- dros_summary |> pull(max_nm)
possible_ks <- seq(0, max_k)

all_theor_probs <- dpois(possible_ks,
  lambda = sample_mean
)

print(all_theor_probs)
     [1] 0.003326341 0.018979711 0.054147999 0.102987370 0.146908454 0.167648471
 [7] 0.159430409 0.129955880 0.092689120 0.058763691 0.033529870 0.017392500

    We can then multiply all of them simultaneously by the number of populations.

    all_theor_counts <- all_theor_probs * n_populations
print(all_theor_counts)
     [1] 0.0565478 0.3226551 0.9205160 1.7507853 2.4974437 2.8500240 2.7103170
 [8] 2.2092500 1.5757150 0.9989827 0.5700078 0.2956725

    This is our theoretical Poisson distribution over the range of mutation counts observed in our data.

    We can add it to our plot. To do so, it needs to be in its own data frame.

    theor_df <- tibble(
  k = possible_ks,
  Theoretical_Mutation_Count = all_theor_counts
)
    NoteInclude this code

    Include this code in your drosophila.qmd Quarto file.

    Combining the steps above, the full code block to generate the theoretical data frame is as follows:

    # Find the maximum observed value of k
max_k <- dros_summary |> pull(max_nm)

# Make a sequence of numbers from 0
# to the observed maximum k
possible_ks <- seq(0, max_k)

# Extract the sample mean from the summary data frame
sample_mean <- dros_summary |> pull(mean_nm)

# Calculate the theoretical distribution
all_theor_probs <- dpois(possible_ks,
  lambda = sample_mean
)
all_theor_counts <- all_theor_probs * n_populations

# Put the results in a data frame
theor_df <- tibble(
  k = possible_ks,
  Theoretical_Mutation_Count = all_theor_counts
)

    We can now add the theoretical points to our plot using geom_point(). We can give this function the new data frame to use instead of dcounts.

    NoteInclude this code

    Include this code in your drosophila.qmd Quarto file.

    ## fill='skyblue', size=3, and theme_bw are not essential, just aesthetic
ggplot(data = dcounts, mapping = aes(x = Novel_Mutation_Count)) +
  geom_bar(fill = "skyblue") +
  geom_point(data = theor_df, mapping = aes(
    x = k,
    y = Theoretical_Mutation_Count
  ), size = 3) +
  theme_bw()

    Again, the data looks kind of Poisson distributed, but it is not particularly definitive.

    One explanation for the difference between the sample mean and variance is the small sample size. This would also explain why our data don’t look like an ideal Poisson distribution.

    We only have 17 populations, so the values we calculate from our sample will not exactly match the true properties of the underlying distribution. Even if the mutations really do follow a Poisson distribution, different random samples of only 17 populations will likely give slightly different means and variances simply due to chance.

    Simulation

    This is another case where simulating data is really helpful. Let’s simulate some data sets which are definitely Poisson distributed and have a sample size of 17, and see how they look.

    We can use the rpois function for this.

    First, let’s generate simulated mutation counts on chromosome 2R for 17 populations.

    simulated_counts <- rpois(
  n = n_populations,
  lambda = sample_mean
)
print(simulated_counts)
     [1]  1  8  1  4  9  6  5  5  2 11  5 10  9  6 11  6  5

    This vector has a mean and a variance, just like our real counts.

    print(mean(simulated_counts))
    [1] 6.117647
    print(var(simulated_counts))
    [1] 10.11029

    By simulating lots of similar datasets, we can establish if the difference between the mean and variance we saw with our real data is consistent with this data, which we know is Poisson distributed.

    The difference we saw in our real data is easy to calculate.

    sample_mean <- dros_summary |>
  pull(mean_nm)
sample_variance <- dros_summary |>
  pull(variance_nm)

sample_diff <- abs(sample_mean - sample_variance)

    We saw a difference of 2.01 between the two values.

    ExerciseExercise 3

    In your drosophila.qmd Quarto file, simulate the mutation counts on chromosome 2R for 17 populations 1000 times.

    Store the mean of each simulation in a vector mean_sim and the variance of each simulation in another vector var_sim.

    Make a new data frame, stored as the variable df_sim, where the column mean contains your simulated means and the column var contains your simulated variances.

    Then, add a third column, diff, which shows the absolute value (function abs()) of the difference between the mean and the variance.

    AnswerAnswer 
    mean_sim <- c()
var_sim <- c()
for (i in seq_len(1000)) {
  # Simulate the counts
  simulated_counts <- rpois(
    n = n_populations,
    lambda = sample_mean
  )

  # Take the mean and variance of the simulated counts
  current_mean <- mean(simulated_counts)
  current_var <- var(simulated_counts)

  # Add these to your vectors
  mean_sim <- c(mean_sim, current_mean)
  var_sim <- c(var_sim, current_var)
}

df_sim <- tibble(
  mean = mean_sim,
  var = var_sim,
  diff = abs(mean_sim - var_sim)
)

    Now, let’s plot histograms of the 1000 differences between the mean and variance we calculated and see how they compare to our value of 2.01.

    ExerciseExercise 4

    You can add a histogram in ggplot using the function geom_histogram(). Like geom_bar() it only requires one mapping, the x axis variable, in this case the difference between the mean and variance. The y axis frequencies are calculated from the data.

    You can change the number of bins in the histogram using the argument bins = n, where n is the number of bins.

    Comparing real, simulated and expected data - continuous distributions

    Whatever type of distribution our data is from, this process is very similar.

    There are some very minor differences when looking at a continuous variable instead of a discrete variable.

    For example, in this paper published in Diversity in 2023, Engelman estimated the body size of an extinct fish, Dunkleosteus terrelli, by looking at fossils and at the correlations between various measurements in other fish.

    We will look at the data set they generated by taking various measurements of other fish, in particular, the lamprey Geotria macrostoma and determine if the total length of these fish is normally distributed.

    The data, which are identical to Supplementary File S1 from the paper, are saved as data/fish.csv.

    ExerciseExercise 5

    In your distributions.qmd Quarto file: * Read the file fish.csv into a data frame variable. Use the clean_names() function to clean the column names. * Filter the data to keep only rows where the genus column is equal to Geotria, store the result as a variable named geo. * Plot the column total_length_cm as a histogram

    Do you think this data is normally distributed?

    AnswerAnswer 
    # Read the data
fish <- read_csv("data/fish.csv") |> clean_names()

# Filter to keep only the genus Geotria
geo <- fish |> filter(genus == "Geotria")

# Plot a histogram
ggplot(geo, aes(x = total_length_cm)) +
  geom_histogram()

    The data looks basically normally distributed.

    With continuous data, the probability distribution is described by a probability density function (PDF) rather than a PMF. The theoretical distribution is therefore represented by a continuous curve rather than probabilities at a series of discrete values.

    So that our data is comparable with the PDF, we can easily transform our data to show density, rather than counts, using the function after_stat() with the argument density, which we use as a mapping to the geom_histogram() function. after_stat(density) rescales the histogram so that its total area is 1, allowing it to be compared directly with a probability density function.

    ggplot(geo, aes(
  x = total_length_cm
)) +
  geom_histogram(aes(y = after_stat(density)),
    bins = 30
  )

    It might be helpful to compare our data to a perfect, theoretical normal distribution. For a continuous distribution, it’s very easy to add a theoretical distribution to our plot.

    The function stat_function() is used to add a continuous curve, based on a function, onto a plot.

    The arguments are:

    • fun - the name of a function
    • args - a list of the arguments to that function

    In our case, the function is dnorm() - the PDF for the normal distribution. The arguments are the two parameters of the normal distribution dnorm() - mean and standard deviation.

    So, we would call this function as:

    stat_function(fun = dnorm, args = list(mean = mean_obs, sd = sd_obs))

    Where mean_obs is the mean observed total fish length from our data and sd_obs is the standard deviation of the same data.

    We can add this directly to the plot using the same plotting code as before, but with this function as an extra layer.

    # Calculate the observed mean and standard deviation
mean_obs <- mean(pull(geo, total_length_cm))
sd_obs <- sd(pull(geo, total_length_cm))

# Draw the plot
ggplot(geo, aes(
  x = total_length_cm
)) +
  geom_histogram(aes(y = after_stat(density)),
    bins = 50
  ) +
  stat_function(
    fun = dnorm,
    args = list(mean = mean_obs, sd = sd_obs)
  )

    One property that can help us describe how the shape of a distribution differs from a normal distribution is skewness - a measure of the asymmetry of the distribution

    We can calculate this using the R functions skewness() from the package moments.

    The theoretical normal distribution has a skewness of 0. However, a finite sample drawn from a normal distribution will not usually have a skewness of exactly 0.

    The only argument to this function is our observed data vector.

    # Pull the total_length_cm column from the geo data frame
body_length <- geo |> pull(total_length_cm)

# Calculate the skewness
skew <- skewness(body_length)
print (skew)
    [1] -0.148105

    Our observed value is -0.15 — reasonably close to 0. But how close should we expect it to be for a sample of this size? Let’s simulate normally distributed data for comparison.

    ExerciseExercise 6

    In your distributions.qmd Quarto file:

    • For 10,000 repeats, using the rnorm() function, generate the same number of data points (you can count how many rows are in the data frame with the function nrow()) as in the geo table with the same mean (function mean()) and standard deviation (function sd()) as Geotria.
    • Store the skewness for each simulation as a vector.
    • Calculate the proportion of simulated datasets which were more skewed than the observed data.
    AnswerAnswer

    For 10,000 repeats, using the rnorm() function, generate the same number of data points as in the geo table with the same mean and standard deviation as Geotria.

    Store the skewness for each simulation as a vector.

    nrow_obs <- nrow(geo)
mean_obs <- mean(pull(geo, total_length_cm))
sd_obs <- sd(pull(geo, total_length_cm))

skews <- c()

for (i in seq_len(10000)){
  points <- rnorm(nrow_obs, mean = mean_obs, sd = sd_obs)
  skew <- skewness(points)
  skews <- c(skews, skew)
}

skew_df <- tibble(Skewness = skews)

    Calculate the proportion of simulated datasets which were more skewed than the observed data.

    # Retrieve the observed skewness
body_length <- geo |> pull(total_length_cm)
skew_obs <- skewness(body_length)
# Calculate the absolute value of the observed skewness
abs_skew_obs <- abs(skew_obs)

# Calculate the absolute value of the simulated skewness
abs_skew_sim <- abs(skews)

# Count how many times this is more than our observed skewness
more_than_obs <-sum(abs_skew_sim > abs_skew_obs)

# Count the proportion of times this is more than our observed skewness
skew_prop_more_than_obs <- more_than_obs / 10000

print (skew_prop_more_than_obs)
    [1] 0.2592

    25.92% of our simulated normal distributions are more skewed than our observed data.

    The observed skewness is therefore consistent with what we might expect from a sample of this size drawn from a normal distribution - i.e. if the body length of the whole population of Geotria is normally distributed.

    NoteProgramming summary
    • R uses a consistent set of functions for working with probability distributions:
      • r...() generates random values from a distribution.
      • d...() calculates probabilities for discrete distributions or probability densities for continuous distributions.
      • p...() calculates cumulative probabilities.
      • q...() calculates quantiles.
    • rpois() generates random values from a Poisson distribution.
    • rnorm() generates random values from a normal distribution.
    • geom_bar() can be used to plot the distribution of discrete observations.
    • geom_histogram() can be used to plot the distribution of continuous observations.
    • after_stat(density) rescales a histogram to show probability density rather than counts.
    • stat_function() can be used to add a theoretical probability density function to a plot.
