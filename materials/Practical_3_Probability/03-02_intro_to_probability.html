    Introduction to simulation

    Many biological processes involve an element of chance and therefore involve probability. In R, we can use simulation to generate data that approximates a random processes. These simulated data allow us to investigate probability, test hypotheses and better understand the behaviour of biological systems.

    If you are studying a stochastic process, the exact probability of an event can sometimes be calculated mathematically. In these cases, simulation provides a useful way to check your calculations. In other cases, an exact solution may be difficult or impossible to obtain, and simulation allows you to estimate the answer instead.

    How to simulate data

    First, let’s perform a tiny simulation, of a coin toss.

    We are using the function sample(), with the arguments x - the elements from which to sample, and size, the number of samples to take. By default, R assumes that every element is equally probable.

    coin_toss <- sample(c("Heads", "Tails"), size = 1)
print(coin_toss)
    [1] "Heads"

    We can use a for loop to toss multiple coins.

    for (i in seq_len(5)) {
  coin_toss <- sample(c("Heads", "Tails"),
                      size=1)
  print(coin_toss)
}
    [1] "Heads"
[1] "Heads"
[1] "Heads"
[1] "Tails"
[1] "Tails"

    We can also do this directly with the sample function by changing size. We need to add the argument replace = TRUE to tell R to replace the samples - otherwise after two samples, the coin has no remaining sides!

    coin_tosses <- sample(c("Heads", "Tails"),
                      size=5,
                      replace = TRUE)
print(coin_tosses)
    [1] "Tails" "Tails" "Heads" "Tails" "Heads"

    To count how many times a specific value occurs in a vector, you can use the operator == and the sum() function:

    n_successes <- sum(coin_tosses == "Heads")
print(n_successes)
    [1] 2

    The coin showed Heads 2 times.

    Unequal probabilities

    So far, we’ve assumed a “fair coin” - with 50% probability of each outcome. However, we can change this by giving an additional argument to the sample() function.

    This argument is prob - a vector of probability weights corresponding to the elements of the original vector.

    So, if we want the coin to land on heads 70% of the time, we would use:

    coin_tosses <- sample(c("Heads", "Tails"),
  size = 5,
  replace = TRUE,
  prob = c(0.7, 0.3)
)
print(coin_tosses)
    [1] "Tails" "Tails" "Heads" "Heads" "Tails"

    If we had a vector c('Badger', 'Mushroom', 'Snake') and we want to sample 100 times from this vector, with replacement, selecting Badger 95% of the time, Mushroom 4% of the time and Snake 1% of the time, we would use this function as follows:

    bm_vec <- c("Badger", "Mushroom", "Snake")
bm_probs <- c(0.95, 0.04, 0.01)

my_sample <- sample(bm_vec,
  size = 100,
  replace = TRUE,
  prob = bm_probs
)
print(my_sample)

    Repeating simulations

    If you run this simulation several times, you’ll see that the result often changes.

    We can formalise this using a for loop, running the simulation a fixed number of times.

    Let’s say we have 1000 squirrels, each making 150 attempts, with the same fixed probability of success of 30%.

    combined_successes <- c()
for (i in seq_len(1000)) {
  is_success <- sample(c("SUCCESS", "FAILURE"),
    size = 150,
    replace = TRUE,
    prob = c(0.3, 0.7)
  )
  n_successes <- sum(is_success == "SUCCESS")
  combined_successes <- c(combined_successes, n_successes)
}
print(combined_successes)

    Let’s visualise how many squirrels have each number of successful heists - i.e. how many of our 1000 squirrels stole seeds once, twice, three times etc.

    First, we need to convert our vector into a data frame.

    Then we can create a plot showing how many squirrels had each number of successful heists.

    The geom_bar() function in ggplot counts how many times each value occurs in a column of a data frame and displays the result as a bar chart.

    geom_bar() just needs the x axis to be specified - in this case the N_Successful_Heists column, as the y axis will be calculated.

  df_squirrels,
  aes(

    You can see that a distribution is emerging here - the squirrels are likely to be successful around 40 to 55 times out of 150.

    This is called an empirical distribution because it is based on simulated observations rather than a mathematical formula.

    The binomial distribution

    As you may have recognised, this approximates a binomial distribution:

    • We have a fixed number of trials - 150.
    • We have a binary outcome - success or failure.
    • Our trials are independent.
    • The probability of success is constant across trials.

    The number of successes announced by the squirrel above is the random variable - the number of successes, k out of 150 trials.

    Increasing the number of simulations reduces the random variation in our estimate, bringing it closer to the theoretical distribution. Therefore, if we run our simulation more times, our empirical approximation should get closer to a theoretical binomial distribution.

    Using probability functions in R

    As you learned in the lectures, the probability mass function (PMF) for the binomial distribution is:

    \[ P(X = k) = \binom{n}{k} p^k (1-p)^{n-k} \]

    This is implemented in R with the function dbinom().

    The arguments for this function are:

    • x: calculate the number of successes - k in the equation,
    • size: number of trials, n in the equation, in our case 150 attempts per squirrel
    • prob: probability of success in each trial - p in the equation, the probability of squirrel success, 0.3, in our case.

    Let’s estimate the probability that a squirrel succeeds 48 times.

    n <- 150
k <- 48
p <- 0.3

prob_X_equals_k <- dbinom(k, n, p)
print(prob_X_equals_k)
    [1] 0.06051733

    We would expect this result around 6% of the time.

    Let’s compare this with the observed result from our simulation. Using filter, we can view the row showing how many squirrels succeeded 48 times.

    n_successes <- pull(df_squirrels, N_Successful_Heists)
prop_48 <- sum(n_successes == 48)
print (prop_48)
    [1] 57

    In my version of the simulation, 57 out of 1000 squirrels succeeded 48/150 times, your results might vary.

    print(prop_48 / 1000)
    [1] 0.057

    This is around 6% of the squirrels - not far off the estimate using the PMF.

    Inbuilt functions

    R is often used for simulation, so there are inbuilt functions to help us.

    Up to this point, we have simulated each individual attempt and then counted the number of successes. Because this type of experiment is so common, R provides a function that generates the number of successes directly.

    With this binomially distributed data, we could have avoided most of the above (sorry) by using the function rbinom(), which automatically draws samples from a binomial distribution.

    This function takes three arguments:

    • n: number of observations, in our case e.g. 1000 squirrels
    • size: number of trials, in our case 150 attempts per squirrel
    • prob: probability of success, in our case 0.3 (30% chance of stealing seeds successfully)
    count_squirrels <- rbinom(n = 1000, size = 150, prob = 0.3)
print(count_squirrels)

    We have already used the function dbinom(), which gives us the probability of a specific number of successes, given specified values of k, n and p.

    Another function, pbinom() calculates the probability that there will be no more than a specific number of successes. This is known as the cumulative probability. The arguments are similar to dbinom:

    • q: calculate the probability of no more than this number of successes.
    • size: number of trials - n in the equation, the number of attempts per squirrel, 150, in our case.
    • prob: probability of success in each trial - p in the equation, the probability of squirrel success, 0.3, in our case.

    For example, to calculate the probability that a squirrel will succeed no more than 48 times:

    prob_up_to_48 <- pbinom(48, 150, 0.3)
print(prob_up_to_48)
    [1] 0.7358792

    We can verify this with our count_squirrels vector generated with rbinom.

    print(sum(count_squirrels <= 48) / length(count_squirrels))
    [1] 0.745
    ExerciseExercise 2

    A botanist studies a plant species in which each flower has a 60% probability of having been pollinated. She needs 125 pollinated flowers for her experiment, but she can’t tell which flowers are pollinated until she gets back to the lab. She picks 200 flowers.

    Using simulation, estimate the probability that she has collected enough pollinated flowers for her experiment.

    Please solve this problem using the rbinom() function in your prac3_exercises.qmd Quarto file.

    Note

    To count how many numbers in a numeric vector, vec, are less than or equal to a certain value, val you can use sum(vec <= val). This syntax also works with other operators (Filtering rows), e.g. <, >, >=, ==, !=.

    AnswerAnswer 
    n_sims <- 1000
n_flowers_per_sim <- 200

# Simulate 1000 datasets of 200 flowers with
# a 60% chance of being pollinated
flowers <- rbinom(
  n = n_sims,
  size = n_flowers_per_sim,
  prob = 0.6
)

# How many times were at least 125 flowers
# pollinated?
times_successful <- sum(flowers >= 125)

# What proportion of the attempts is this?
prop_successful <- times_successful / n_sims
print(prop_successful)
    [1] 0.255

    Based on this simulation, there is an estimated 26% probability she has 125 pollinated flowers.

    We can check this using pbinom().

    # Probability that less than 125 flowers are
# pollinated
prob_under_125 <- pbinom(124, 200, 0.6)

# Probability that more than 125 flowers are
# pollinated
prob_125_or_over <- 1 - prob_under_125

print(prob_125_or_over)
    [1] 0.2589559

    26% - similar to the simulated value. Running more simulations would make the estimate more accurate.
