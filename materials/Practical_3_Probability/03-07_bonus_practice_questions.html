    We will use 10,000 simulations, unless otherwise specified.

    n_sim <- 10000

    Question 1

    In a natural habitat, grey wolves, foxes and coyotes co-exist. The current population is estimated to be 60 foxes, 30 coyotes and 10 wolves. If each animal is equally likely to be sighted first, find the probability of: a. a coyote being sighted first b. a wolf being sighted first c. a fox being sighted second after either a coyote or a wolf has been sighted and then removed from the habitat, so they can be fitted with a tracking device (Consider: what is the impact of the first sighting on what you see next?)

    # Make a population with 60 foxes, 30 coyotes and 10 wolves
animals <- c(
  rep("fox", 60),
  rep("coyote", 30),
  rep("wolf", 10)
)

# Sample 10000 animals, with replacement
samps <- sample(
  x = animals,
  size = n_sim,
  replace = TRUE
)

    a

    Probability that a coyote is sighted first.

    # Count how many samples are coyotes
n_coy <- sum(samps == "coyote")

# What proportion of the total samples is this?
ans <- n_coy / length(samps)

print(ans)
    [1] 0.3082

    The probability a coyote is sighted first is 0.3082

    b

    Probability that a wolf is sighted first.

    # Count how many samples are wolves
n_wolves <- sum(samps == "wolf")

# What proportion of the total samples is this?
ans <- n_wolves / length(samps)
print(ans)
    [1] 0.1062

    The probability a wolf is sighted first is 0.1062

    c

    Probability of a fox being sighted second after either a coyote or a wolf has been sighted and then removed from the habitat, so they can be fitted with a tracking device.

    times_w_c_first <- 0
times_f_second <- 0

first_animal <- c()
second_animal <- c()
for (i in seq_len(n_sim)) {
  # Sample 2 animals from the habitat
  # and remove each after sampling
  samps <- sample(
    x = animals,
    size = 2,
    replace = FALSE
  )
  # Track who was caught first
  first_animal <- c(first_animal, samps[1])

  # Track who was caught second
  second_animal <- c(second_animal, samps[2])
}

# Vector of all the times wolf or coyote was
# first
w_c_first <- first_animal %in% c("wolf", "coyote")

# Vector of all the times fox was second
fox_second <- second_animal == "fox"

# Count how many times a wolf or coyote was
# first
w_c_first_count <- sum(w_c_first)

# Count how many times a wolf or coyote was
# first and a fox was second
w_c_first_and_fox_second_count <- sum(w_c_first & fox_second)

# Calculate the proportion of the times that
# a wolf or coyote was first that a fox was
# also second
ans <- w_c_first_and_fox_second_count / w_c_first_count
print(ans)
    [1] 0.6121645

    The probability of a fox being sighted second after either a coyote or a wolf has been sighted and then removed from the habitat 0.6122

    Question 2

    A transmitter emits the signals “0” or “1” in the ratio 1:2. Two independent receivers, labelled R1 and R2 are set up. If, unknown to the users, receiver R1 is incorrect in 2% of the cases and receiver R2 is incorrect in 3% of the cases, find

    1. the probability that R1 reports that the transmitted signal is “0”
    2. the probability that R2 reports that the transmitted signal is “1”
    3. following an incoming signal there is some confusion, because R1 reports signal “0” and R2 reports signal “1”. Which of the two receivers is most likely to be correct?
    # Run the transmitter 10,000 times, with a 2/3 probability of success
# where success == 1
transmitter <- rbinom(n = n_sim, size = 1, prob = 2 / 3)

# Run R1 10,000 times, with a 98% probability of success
# 1 - correct
# 0 - incorrect
R1_correct <- rbinom(n = n_sim, size = 1, prob = 0.98)

# Run R2 10,000 times, with a 97% probability of success
# 1 - correct
# 0 - incorrect
R2_correct <- rbinom(n = n_sim, size = 1, prob = 0.97)

    a

    The probability that R1 reports that the transmitted signal is “0”

    # R1 reports 0 when either the signal is 0
# and it is correct or the signal is 1
# and it is incorrect
zero_and_correct <- transmitter == 0 & R1_correct == 1
one_and_incorrect <- transmitter == 1 & R1_correct == 0

# Find times when either of these are true
# | = OR
R1_output_of_zero <- zero_and_correct | one_and_incorrect

# Count how many times either were true
count_R1_output_of_zero <- sum(R1_output_of_zero)

# Convert to a proportion
ans_a <- count_R1_output_of_zero / n_sim
print(ans_a)
    [1] 0.3441

    The probability that R1 reports that the transmitted signal is “0” is 0.3441

    b

    The probability that R2 reports that the transmitted signal is “1”

    # R2 reports 1 when either the signal is 1
# and it is correct or the signal is 0
# and it is incorrect
one_and_correct <- transmitter == 1 & R2_correct == 1
zero_and_incorrect <- transmitter == 0 & R2_correct == 0

# Find times when either of these are true
R2_output_of_one <- one_and_correct | zero_and_incorrect

# Count how many times either were true
count_R2_output_of_one <- sum(R2_output_of_one)
ans_b <- count_R2_output_of_one / n_sim

print(ans_b)
    [1] 0.6513

    The probability that R2 reports that the transmitted signal is “1” is 0.6513

    c

    1. following an incoming signal there is some confusion, because R1 reports signal “0” and R2 reports signal “1”. Which of the two receivers is most likely to be correct?
    # Find when R1 reports 0 and R2 reports 1
R1_0_R2_1 <- (R1_output_of_zero == 1) & (R2_output_of_one == 1)

# Count how many of these times R1 reports 0 and is correct
R1_reports_zero_correctly <- sum(R1_correct == 1 & R1_0_R2_1 == 1)

# Count how many of these times R1 reports 0 and is correct
R2_reports_one_correctly <- sum(R2_correct == 1 & R1_0_R2_1 == 1)

# Calculate the proportion of times R1 is correct
R1_correct_prop <- R1_reports_zero_correctly / sum(R1_0_R2_1 == 1)
R2_correct_prop <- R2_reports_one_correctly / sum(R1_0_R2_1 == 1)


print(paste("R1 = ", R1_correct_prop))
    [1] "R1 =  0.40174672489083"
    print(paste("R2 = ", R2_correct_prop))
    [1] "R2 =  0.59825327510917"

    Given that R1 has reported 0 and R2 has reported 1, R2 is more likely to be correct, with a probability of 0.5983, compared to 0.4017 for R1.

    # Make a batch of 12 healthy and 10 infested trees

    Question 4

    A spam filter on a mail server scrutinises messages for the appearance of key words that make it likely that the message is spam.

    The filter works as follows: • it is assumed that evidence for spam is that the subject message of the email contains the sentence “check this out”.

    According to some historical data we know that: • 40% of emails are spam • 1% of spam emails have “check this out” in the subject line • 0.4% of non-spam emails have “check this out” in the subject line. Find the probability that an email is spam given that it has the phrase “check this out” in the subject

    # Simulate 100,000 emails with a 40% chance of being spam
# 1 = spam
# 0 = not spam
is_spam <- rbinom(100000, size = 1, prob = 0.4)

# Count how many of these are and are not spam
n_spam <- sum(is_spam == 1)
n_not_spam <- 100000 - n_spam

# For the results which are spam, simulate a 1% chance
# of saying CTO
is_cto_spam <- rbinom(n_spam, size = 1, prob = 0.01)

# For the results which are not spam, simulate a 0.4% chance
# of saying CTO
is_cto_not_spam <- rbinom(n_not_spam, size = 1, prob = 0.004)

# Calculate the total number of simulations that are CTO
cto <- sum(is_cto_spam, is_cto_not_spam)

# Calculate the proportion of CTO simulations which are spam
prob_spam_cto <- sum(is_cto_spam) / cto

print(prob_spam_cto)
    [1] 0.627451

    The probability that an email is spam given that it has the phrase “check this out” in the subject is 0.6275

    Note that I used a higher number of simulations here because so few emails have “check this out” overall.

    Question 2

    A drug is produced in a chamber with temperature X, where X is a random variable that follows a normal distribution with μ = 21°C and σ = 5°C. If X<25°C, the production cost per unit is £20, whereas if X≥25°C the production cost per unit is £30. Find the expected production cost per unit for this drug.

    # Simulate a normal distribution where μ = 21°C and σ = 5°C
drug_dist <- rnorm(n_sim, 21, 5)

ans_2 <- total_cost / n_sim

    Question 3

    A box contains 3 green and 5 red balls. If we pick balls and then replace them, find: a) The probability that the third time we pick a ball, we get a red ball for the second time. b) The probability that the 4th time we pick a ball, a red ball appears for the first time c) The expected number of times we pick a ball until we get a red ball for the second time.

    a

    The probability that the third time we pick a ball, we get a red ball for the second time.

    # Draw two balls 10,000 times and count how many
# are red
first_two <- rbinom(n_sim, size = 2, prob = 5 / 8)

# Draw one ball 10,000 times and count how many
# are red
third <- rbinom(n_sim, size = 1, prob = 5 / 8)

# How many times is either ball 1 or ball 2 red
# but not both and ball 3 is red
count <- sum(first_two == 1 & third == 1)

# As a proportion
prop <- count / n_sim

print(prop)
    [1] 0.2989

    The probability that the third time we pick a ball, we get a red ball for the second time is 0.2989.

    b

    The probability that the 4th time we pick a ball, a red ball appears for the first time

    # Draw three balls 10,000 times and count how many
# are red
first_three <- rbinom(n_sim, size = 3, prob = 5 / 8)

# Draw one ball 10,000 times and count how many
# are red
fourth <- rbinom(n_sim, size = 1, prob = 5 / 8)

# How many times are none of the first three balls
# red but ball 4 is red
count <- sum(first_three == 0 & fourth == 1)

# As a proportion
prop <- count / n_sim

print(prop)
    [1] 0.0333

    The probability that the 4th time we pick a ball, a red ball appears for the first time is 0.0333.

    c

    The expected number of times we pick a ball until we get a red ball for the second time.

    # Simulate the number of green balls picked before the first red
# twice
ball_1 <- rgeom(n_sim, 5 / 8)
ball_2 <- rgeom(n_sim, 5 / 8)

# Add them together - add two for the two red balls then picked
combined_balls <- ball_1 + ball_2 + 2

# The mean of these values is the expectation
expected <- mean(combined_balls)

print(expected)
    [1] 3.2095

    The expected number of times we pick a ball until we get a red ball for the second time is 3.2095.

    Question 5

    Note

    Answering this question using simulation depends on the bonus material in Part 6 - Sampling from a user-defined probability distribution.

    A continuous random variable X has the following probability density function: \[ f(x) = \begin{cases} \displaystyle\frac{4x(9-x^2)}{81}, & \text{if } 0 \leq x \leq 3 \\[6pt] 0, & \text{otherwise} \end{cases} \]

    1. Verify that f(x) is a valid probability density function.
    2. Find (a) the mean of f(x), (b) the mode of f(x) and (c) the median of f(x)

    a

    Verify that f(x) is a valid probability density function.

    # Calculate the area under the curve
area <- integrate(
  function(x) {
    ((4 * x) * (9 - x^2)) / 81
  },
  lower = 0,
  upper = 3
)
print(area)
    1 with absolute error < 1.1e-14

    The function is non-negative over its specified range and the area under the curve is 1 so the PDF is valid.

    b

    Find (a) the mean of f(x), (b) the mode of f(x) and (c) the median of f(x)

    # Make a random number generator using this function
rand_gen <- pinv.new(
  pdf = function(x) {
    ((4 * x) * (9 - x^2)) / 81
  },
  lb = 0,
  ub = 3
)

# Generate 10,000 random points
simu <- ur(rand_gen, n_sim)

# Calculate the mean and median of the points
mean_simu <- mean(simu)
median_simu <- median(simu)

# Mean
print(mean_simu)
    [1] 1.602492
    # Median
print(median_simu)

    Let (X) be a continuous random variable with probability density function:

    \[ f(x) = \begin{cases} x^2\left(2x+\frac{3}{2}\right), & \text{if } 0 < x \leq 1 \\ 0, & \text{otherwise} \end{cases} \]

    If

    \[ Y = \frac{2}{X} + 3, \]

    x^2 * (2 * x + (3 / 2))
  },
  lb = 0,
  ub = 1
)

simu <- ur(rand_gen, 100000)

# Calculate the Y value for each point and store it.
simu_y <- c()
for (sim_x in simu) {

    Question 7

    A polar bear is hunting for food. From its current position, there are three different routes. The first one brings it back to the same point after 1 hours of walking. The second route brings it back to the same point after 6 hours of walking. The last route leads to the food source after 2 hours of walking. Assuming that the probability the bear chooses route 1 is 0.25, route 2 is 0.25 and route 3 is 0.5, what is the expected time it will take for the bear gets some food?

    Note

    This solution uses conditional statements if and else, along with a while loop - a loop which runs over and over again until something becomes true. We have not covered these programming techniques in the practicals.

    # Length of each route
route1 <- 1
route2 <- 6
route3 <- 2

# Probability of each route
prob1 <- 0.25
prob2 <- 0.25
prob3 <- 0.5

# Currently, the bear has no food
food <- FALSE

# Vector to track the time taken in each simulation
total_times <- c()

for (i in seq_len(n_sim)) {
  total_time <- 0
  food <- FALSE
  # Keep running these steps until he finds food
  while (!food) {
    # Randomly, based on the probabilities above, choose a route
    which_route <- sample(seq_len(3), 1, prob = c(prob1, prob2, prob3))

    # If it is route 1, add 1 hour to the total time
    if (which_route == 1) {
      total_time <- total_time + route1
    }
    # If it is route 2, add 6 hours to the total time
    else if (which_route == 2) {
      total_time <- total_time + route2
    }
    # If it is route 3, add 2 hours to the total time
    # then stop the loop because he has found food.
    else if (which_route == 3) {
      total_time <- total_time + route3
      food <- TRUE
    }
  }
  # Store the total time taken
  total_times <- c(total_times, total_time)
}
# Calculate the mean of the time taken over the 10,000 simulations
mean_total <- mean(total_times)
print(mean_total)
    [1] 5.4825

    The mean time for the polar bear to find food is 5.4825.
