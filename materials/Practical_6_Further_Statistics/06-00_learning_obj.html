    Part 1: Functions

    Sections

    • Writing functions
    • Returning multiple outputs from a function (Extension)

    Learning objectives

    By the end of this part of the practical you will be able to:

    • Understand what functions are and why they are useful.
    • Write a function that takes an input and returns an output.
    • Apply a function to different values and to columns in a data frame.

    Part 2: Testing Assumptions of Linear Models

    Sections

    • Independent observations
    • Continuous response
    • Normally distributed residuals
    • Q-Q Plot
    • Constant variance of residuals
    • Residuals vs fitted
    • Scale-Location
    • Influential observations
    • Plotting linear models using base R
    • Review

    Learning objectives

    By the end of this part of the practical you will be able to:

    • Describe the main assumptions of linear models.
    • Extract fitted values and residuals from a fitted linear model.
    • Use diagnostic plots to assess normality, constant variance and linearity.
    • Identify potentially influential observations in a linear model.
    • Use R to generate standard diagnostic plots for a fitted linear model.

    Sections

    • Scenarios (Extension)

    Learning objectives

    By the end of this part of the practical you will be able to:

    • Use simulation to investigate the behaviour of a statistical test.
    • Interpret distributions of p-values from repeated statistical tests.
    • Explain how Type I and Type II error rates can be estimated using repeated simulations.
    • Investigate how violations of model assumptions affect the results of a t-test.

    Learning objectives

    By the end of this part of the practical you will be able to:

    • Fit and interpret a binomial generalised linear model (GLM) in R.
    • Explain the role of the logit link function in a binomial GLM.
    • Use a fitted binomial GLM to predict probabilities.
    • Fit binomial GLMs containing multiple explanatory variables and interactions.
    • Describe the main assumptions of a binomial GLM.

    Part 5: Generalised Linear Models - Poisson

    Sections

    • Poisson GLMs
    • Log-link function
    • Fitting Poisson GLMs in R
    • Prediction
    • Assumptions of Poisson GLMs
    • Review

    Learning objectives

    By the end of this part of the practical you will be able to:

    • Explain when a Poisson generalised linear model (GLM) is appropriate.
    • Fit and interpret a Poisson GLM in R.
    • Explain the role of the log link function in a Poisson GLM.
    • Use a fitted Poisson GLM to predict expected counts.
    • Assess whether count data are overdispersed relative to a fitted Poisson model.

    Part 6: Choosing a model

    Sections

    • Nested models and backwards stepwise elimination
    • Likelihood-Ratio tests

    Learning objectives

    By the end of this part of the practical you will be able to:

    • Explain what is meant by nested and minimal models.
    • Compare nested models to determine whether removing an explanatory variable significantly worsens model fit.
    • Use likelihood-ratio tests to compare nested GLMs.
    • Use backwards stepwise elimination to identify a minimal model.
    • Use AIC as an alternative approach to model selection. (Extension)

    Learning objectives

    By the end of this part of the practical you will be able to:

    • Explain statistical power and the factors that affect it. (Extension)
    • Use effect sizes to describe the magnitude of differences or relationships. (Extension)
    • Use analytical power calculations to estimate the sample size required to detect an effect of a specified size. (Extension)
    • Use simulation to estimate statistical power for more complex models. (Extension)
    • Use power analysis to investigate the size of effect that can be reliably detected when sample size is fixed. (Extension)

    Sections

    • P-value distributions
    • Multiple testing

    • Multiple testing corrections

    Learning objectives

    By the end of this part of the practical you will be able to:

    • Explain why p-values are uniformly distributed under the null hypothesis. (Extension)
    • Explain why performing many statistical tests increases the probability of obtaining false-positive results. (Extension)
    • Distinguish between family-wise error rate and false discovery rate. (Extension)
    • Explain how Bonferroni and Benjamini–Hochberg corrections address multiple testing. (Extension)
    • Apply multiple-testing corrections to a set of p-values in R. (Extension)
