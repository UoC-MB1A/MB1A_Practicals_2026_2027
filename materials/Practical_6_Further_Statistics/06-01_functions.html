    Writing functions

    In the practical course so far, we have used many of the different functions (see Functions) which are built into R and provided by additional packages.

    However, it is also possible to write your own functions. This means you can use the same set of instructions multiple times, possibly with different inputs.

    Functions have several advantages:

    • Using the same code again saves time.
    • If you want to change something in the code, you only have to change it once.
    • Because you are writing less code, you are less likely to make mistakes.

    Here is a simple example of a function, to calculate the equivalent age of a dog if it were a human, its age in dog years. According to the BBC, for a medium dog the calculation is:

    \[ d = 21 + \left(4 \times (\text{h} - 2)\right) \]

    Where d is the age in dog years and h is age in human years.

    We can write a function to calculate this. We define a function using the function function(). It is best to give the function a descriptive name.

    The steps of the function are then written in curly brackets ({}) on the following lines.

    The return statement defines what the output of the function will be.

    human_years_to_dog_years <- function(age_in_human_years) {
  age_in_dog_years <- 21 + (4 * (age_in_human_years - 2))
  return(age_in_dog_years)
}

    So here we are saying:

    • human_years_to_dog_years <- function(age_in_human_years): I am defining a function, it is called human_years_to_dog_years and takes one argument, age_in_human_years.
    • {: Here are the steps.
    • age_in_dog_years <- 21 + (4 * (age_in_human_years - 2)): Run this equation on the variable age_in_human_years and store the result as the variable age_in_dog_years.
    • return (age_in_dog_years): Return the value of the variable age_in_dog_years as the output of the function
    • }: That’s all.

    Let’s use our function to calculate the age in dog years of some dogs.

    Monty is 6 in human years.

    print(human_years_to_dog_years(6))
    [1] 37

    Noodle is 2 in human years:

    print(human_years_to_dog_years(2))
    [1] 21

    We can also apply our function to a column in a data frame.

    Let’s say we have this data frame of dogs.

    dog_data <- tibble(
  Name = c(
    "Biscuit",
    "Snowball",
    "Pickle",
    "Artemis",
    "Bert"
  ),
  Age_Human_Years = c(6, 1, 12, 4, 15)
)
gt(dog_data)
    Name Age_Human_Years
    Biscuit 6
    Snowball 1
    Pickle 12
    Artemis 4
    Bert 15

    Using our human_years_to_dog_years() function, we can calculate the age in dog years of each dog.

    Note

    Remember that the mutate() function allows us to create a new column in a data frame by applying a function to an existing column.

    dog_data_updated <- dog_data |>
  mutate(Age_Dog_Years = human_years_to_dog_years(Age_Human_Years))

gt(dog_data_updated)
    Name Age_Human_Years Age_Dog_Years
    Biscuit 6 37
    Snowball 1 17
    Pickle 12 61
    Artemis 4 29
    Bert 15 73

    There are two important things to learn about functions:

    1. In order to run the function, you need to call it

    So, if I just run this code:

    human_years_to_dog_years <- function(age_in_human_years) {
  age_in_dog_years <- 21 + (4 * (age_in_human_years - 2))
  return(age_in_dog_years)
}

    R now knows this function exists, but it hasn’t been used yet.

    If we want to actually run it, we need to add a function call.

    human_years_to_dog_years <- function(age_in_human_years) {
  age_in_dog_years <- 21 + (4 * (age_in_human_years - 2))
  return(age_in_dog_years)
}
# function call
print(human_years_to_dog_years(10))
    [1] 53

    2. Variables you create inside a function only exist inside the function.

    So, the following will work - inside the function, between the curly brackets, we can access the variable age_in_dog_years.

    human_years_to_dog_years <- function(age_in_human_years) {
  print(paste("Age in human years:", age_in_human_years))
  age_in_dog_years <- 21 + (4 * (age_in_human_years - 2))
  return(age_in_dog_years)
}
# function call
print(paste("Age in dog years:", human_years_to_dog_years(10)))
    [1] "Age in human years: 10"
[1] "Age in dog years: 53"

    But this will not work, because outside of the function, the variable age_in_dog_years does not exist.

    human_years_to_dog_years <- function(age_in_human_years) {
  age_in_dog_years <- 21 + (4 * (age_in_human_years - 2))
  return(age_in_dog_years)
}
result <- human_years_to_dog_years(10)
print(paste("Age in human years:", age_in_dog_years))
    Error:
! object 'age_in_dog_years' not found
