    As we discussed in Part 2: Hypothesis Testing, T-tests, ANOVA and linear regression are all based on the same general linear-model framework and therefore share many assumptions.

    Assumption t-test ANOVA Linear regression
    Independent observations ✓ ✓ ✓
    Continuous response ✓ ✓ ✓
    Normally distributed residuals ✓ ✓ ✓
    Constant variance of residuals ✓* ✓ ✓
    Linear relationship with continuous explanatory variables — — ✓
    • For a standard two-sample t-test, equal variance is assumed. Welch’s t-test does not assume equal variance.

    In the previous practical, we assumed the assumptions of all our models had been met, however, in reality we should always check this before carrying out a test.

    Independent observations

    Each observation should be independent of the others. For example, repeated measurements from the same site should not usually be treated as independent observations. Whether observations are independent depends primarily on how the data were collected. This is a study design step rather than an analysis step.

    Continuous response

    The response variable should be continuous, e.g. mass, temperature, distance. Standard linear models assume that the response can vary continuously around the value predicted by the model. Binary responses, categorical responses and counts generally require different types of model.

    Normally distributed residuals

    The residuals — the differences between the observed values and the values predicted by the model — should be approximately normally distributed.

    We can also access the fitted (predicted) values directly from the model using the function fitted(). In this example they are not especially interesting, because there are only two possible fitted values: the mean minimum temperature for sites where H. tumulorum is absent and the mean for sites where it is present.

    Nevertheless, let’s put our fitted and residual values into a data frame, to make our diagnostic plots easier.

    We’re going to do this several times, so let’s write a function to make it easier. We can also add two more outputs of the model which we will need for later plots: * Standardised residuals - these express each residual relative to its expected variability, making residuals easier to compare with one another, and can be extracted using the R function rstandard(). * Square root of absolute value of standardised residuals.

    This function takes the linear model fitted to the data as its input and returns a data frame of the diagnostic statistics.

    get_diagnostic_stats <- function(linear_model){
  diag_stats <- tibble(
    fitted = fitted(linear_model),
    residual = residuals(linear_model),
    standardised_residual = rstandard(linear_model),
    sqrt_abs_standardised_residual = sqrt(abs(standardised_residual))
  )
  return (diag_stats)
}

    Q-Q Plot

    However, there is more we can do to check this assumption.

    A Q–Q (quantile–quantile) plot compares two distributions by plotting their quantiles against each other. In this case, the quantiles of the residuals are compared with the theoretical quantiles of a normal distribution. If the residuals are approximately normally distributed, the points should approximately follow the straight line.

    To plot the Q-Q plot, we can use the functions stat_qq() and stat_qq_line(). stat_qq() creates the Q–Q plot and stat_qq_line() adds a reference line showing the pattern expected if the residuals follow the theoretical distribution.

    ggplot(ht_diagnostics, aes(sample = residual)) +
  stat_qq() +
  stat_qq_line() +
  theme_bw()

    If the points lie approximately along a straight line, the data are reasonably consistent with a normal distribution. Small deviations are expected, particularly at the ends of the plot. Clear systematic patterns, such as strong curvature or points far from the line, suggest that the normality assumption may not be appropriate.

    Here the points lie reasonably close to the straight line, so there is no strong evidence that the residuals deviate from a normal distribution.

    How normal is normal?

    Linear models are generally robust to moderate deviations from normality, particularly with larger sample sizes. However, substantial deviations from normality or extreme outliers may make hypothesis tests and confidence intervals less reliable.

    What does this actually mean?

    Writing a function

    We are going to repeat the same steps several times in this exercise, so, let’s write another function.

    Let’s take a vector of data points as the input to our function, and have the function: * Put the points into a data frame. * Plot a histogram of the distribution of the points. * Draw a Q-Q plot.

    Note that in this exercise we are just looking whether a set of data points is normally distributed, rather than specifically residuals, so we don’t need our diagnostic statistics.

    diag_normal <- function(data_points) {
  # Make the data frame
  df_points <- tibble(observations = data_points)
  # Plot a histogram of the distribution of the points
  histo <- ggplot(
    df_points,
    aes(x = observations)
  ) +
    geom_histogram(bins = 25)
  # Plot the Q-Q plot
  qq <- ggplot(
    df_points,
    aes(sample = observations)
  ) +
    stat_qq() +
    stat_qq_line() +
    theme_bw()
  # todo_katy - teach patchwork somewhere
  return (histo + qq)
}

    Skewed data

    Now, let’s see what happens if our data is skewed. For example, most of our dogs have been to the hairdresser for a trim, with a few exceptions, so the data is skewed to the right (Note: A right skew means that the right-hand tail of the distribution is longer; most observations are therefore towards the left.)

    This data would not be an exponential distribution - these dogs’ moustache lengths are not the waiting times between events in a Poisson distribution. However, an exponential distribution is a good shortcut to a right-skewed distribution.

    Constant variance of residuals

    Scale-Location

    An alternative diagnostic is the Scale–Location plot. This plots the square root of the absolute standardised residuals against the fitted values. Standardised residuals express each residual relative to its expected variability, making residuals easier to compare with one another.

    In some cases, this makes changes in residual variability easier to see

    We already calculated these values above using our get_diagnostic_stats() function - we extracted them from the model using the R function rstandard(), then applied the abs() function to get the absolute values, then the sqrt() function to get the square root.

    We can now plot the square root of the absolute values of the standardised residuals against our fitted values.

    ggplot(
  temp_prec_diagnostics,
  aes(x = fitted, y = sqrt_abs_standardised_residual)
) +
  geom_point() +
  geom_smooth(se = FALSE) +
  theme_bw()
    `geom_smooth()` using method = 'loess' and formula = 'y ~ x'

    Again, this looks like the equal variance assumption has been met.

    If the assumption of equal variance is not met, the plot will look a bit different.

    Linear relationship with continuous explanatory variables

    For linear regression, we also assume that the relationship between the response variable and each continuous explanatory variable is appropriately described as linear.

    The Residuals vs Fitted plot can be re-used to assess this assumption. If a linear model is appropriate, there should be no systematic pattern in the residuals, and the smoothed line should remain approximately horizontal around zero. A curved pattern suggests that the relationship has not been adequately described by a straight line.

    Let’s revisit our temperature vs precipitation residuals vs fitted plot again.

    ggplot(

) +

  theme_bw()
    `geom_smooth()` using method = 'loess' and formula = 'y ~ x'

    Here, the smoothed line shows some curvature rather than remaining completely horizontal around zero. This suggests that the relationship may not be perfectly linear, although the deviations are relatively modest and are particularly pronounced towards the ends of the range where there are fewer observations.

    Influential observations

    The assumptions we have considered so far apply to the model as a whole. However, individual observations can also have a large influence on the results of a linear model.

    An observation has high leverage if it has an unusual value, or combination of values, for the explanatory variables.

    An observation with high leverage does not necessarily cause a problem. However, an observation that has both high leverage and a large residual may have a substantial influence on the fitted model.

    We need to add two more columns to our diagnostics for our temperature / precipitation regression:

    • Leverage - a measure of the unusualness of the value of the explanatory variable (or combination of variables).
    • Cook’s distance - a measure of how much the regression would change if this point was not included

    We can extract both of these from the model, using the functions hatvalues() for leverage and cooks.distance() for Cook’s distance.

    temp_prec_diagnostics_influ <- temp_prec_diagnostics |>
  mutate(
    leverage = hatvalues(lm_temp_prec),
    cooks_distance = cooks.distance(lm_temp_prec),
  )

    Plotting linear models using base R

    So far, we have always used ggplot for plotting in R in these practicals. However, in this case, there is a shortcut to producing all four of these diagnostic plots in base R - we can just call the function plot() and then give the linear model as an argument.

    The information in these plots is very similar to the plots we have produced manually, but it can be quicker to generate them using this simple function.
