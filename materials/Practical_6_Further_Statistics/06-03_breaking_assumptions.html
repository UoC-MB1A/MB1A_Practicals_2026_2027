    TipLearning objectives

    A standard two-sample t-test assumes that the populations being compared are normally distributed and that their residuals have equal variance, but the t-test is often described as robust to violations of these assumptions. What does this actually mean?

    Let’s investigate two sets of hypotheses, in one we will simulate a true difference in means and in the other we will not.

    Data

    Scenario 1

    • Alternative: The mean running speed of cats through a course is associated with the colour of their fur.
    • Null: The mean running speed of cats through a course is not associated with the colour of their fur.

    Population values:

    • Orange cats: mean speed, 20km/h
    • Black cats: mean speed, 20km/h

    Scenario 2

    • Alternative: The mean running speed of dogs through a course differs depending on whether there is a biscuit at the end of the course.
    • Null: The mean running speed of dogs through a course does not differ depending on whether there is a biscuit at the end of the course.

    Population values:

    • Biscuit absent: mean speed, 20km/hr
    • Biscuit present: mean speed, 24km/hr

    For the cat data, the null hypothesis is true, so the proportion of significant results estimates a Type I error rate.

    For the dog data, the alternative hypothesis is true, so the proportion of non-significant results estimates a Type II error rate.

    Helper functions

    We are going to perform the same steps lots of times, so we need a function.

    ExerciseExercise 1

    In your break_t.qmd Quarto file:

    • Write a function named compare_vectors for which the input is two vectors of measurements. The function should:
      • Create a data frame with two columns, “group” and “measurement”, where each vector contributes one group. As our groups won’t always be the same size, a good option is to create one data frame per group then combine them with bind_rows().
      • Create a summary data frame containing the mean and standard deviation of each group
      • Perform an equal variance t-test comparing the measurements for the two groups.
      • Fit a linear model to the measurements for the two groups.
      • Put the residuals from the linear model into the long format data frame.
      • Plot a histogram showing the distribution of the residuals in each group.
      • Return a list containing:
        • df - The data frame
        • summ_df - The summary data frame
        • t_test - The t-test result
        • linear_model - The fitted linear model
        • distri - the plotted distribution
    AnswerAnswer 
    compare_vectors <- function(vector1, vector2) {
  # Create the data frame
  v1_df <- tibble(group = "group_1",
                  measurement = vector1)
  v2_df <- tibble(group = "group_2",
                  measurement = vector2)
  comp_df <- bind_rows(v1_df, v2_df)

  # Create a summary data frame
  summ_df <- comp_df |>
    group_by(group) |>
    summarise(
      group_mean = mean(measurement),
      group_sd = sd(measurement)
    )

  # Do the t-test
  t_test <- t.test(measurement ~ group,
    data = comp_df,
    var.equal = TRUE
  )

  # Fit the linear model
  linear_model <- lm(measurement ~ group, data = comp_df)

  # Put the residuals from the linear model into the
  # data frame
  comp_df <- comp_df |> mutate(
    residuals = linear_model$residuals
  )

  # Plot a histogram showing the distribution of the
  # residuals in each group.
  distri <- ggplot(comp_df, aes(x = residuals)) +
    geom_histogram(bins=15) +
    facet_wrap(~group) +
    theme_bw()

  # Put the results into a list
  results <- list(
    df = comp_df,
    summ_df = summ_df,
    t_test = t_test,
    linear_model = linear_model,
    distri = distri
  )
  # Return the list
  return(results)
}

    This function will be useful for thoroughly examining a single dataset, however we also want to repeat our analysis on multiple simulated datasets and store only the t-test results.

    We can use a shortened version of this function in this case.

    compare_vectors_short <- function(vector1, vector2) {
  # Create the data frame
  v1_df <- tibble(group = "group_1",
                  measurement = vector1)
  v2_df <- tibble(group = "group_2",
                  measurement = vector2)
  comp_df <- bind_rows(v1_df, v2_df)

  # Do the t-test
  t_test <- t.test(measurement ~ group, data = comp_df, var.equal = TRUE)

  # Return the t-test p-value
  return(t_test$p.value)
}

    Distributions of p-values

    When we repeat a statistical test many times, we can examine the distribution of the p-values it produces.

    When the null hypothesis is true and the test is working correctly, p-values should be approximately uniformly distributed between 0 and 1. For example, around 5% should be less than or equal to 0.05, giving the expected 5% type I error rate.

    For example, here is a very clean scenario of two fairly big, normally distributed groups with the same mean and variance.

    ps <- c()
for (i in seq_len(10000)){
  group_1 <- rnorm(100, mean = 10, sd = 5)
  group_2 <- rnorm(100, mean = 10, sd = 5)

  t_test <- t.test(group_1, group_2, var.equal = TRUE)
  ps <- c(ps, t_test$p.value)
}
p_df <- tibble(pval = ps)

ggplot(p_df, aes(x = pval)) +
  geom_histogram(boundary = 0, binwidth = 0.05) +
  theme_bw()

    When the alternative hypothesis is true, we expect more small p-values. The stronger the evidence the test is able to detect, the more strongly the distribution will be concentrated towards zero.

    For example, here is a very clean scenario of two fairly big, normally distributed groups with a different mean and the same variance.

    ps <- c()
for (i in seq_len(10000)){
  group_1 <- rnorm(100, mean = 10, sd = 5)
  group_2 <- rnorm(100, mean = 13, sd = 5)

  t_test <- t.test(group_1, group_2, var.equal = TRUE)
  ps <- c(ps, t_test$p.value)
}
p_df <- tibble(pval = ps)

ggplot(p_df, aes(x = pval)) +
  geom_histogram(boundary = 0, binwidth = 0.05) +
  theme_bw()

    Therefore, if we are running many tests we can use p-value distributions to investigate whether a statistical test is behaving as expected, rather than judging it from the result of a single test.

    In this first analysis, the data explicitly meet the assumptions for a t-test, as we have drawn them from a normal distribution and fixed the standard deviation.

    Therefore, our diagnostic plots are within the range of deviations which are possible with data which does meet the t-test assumptions, even if they are imperfect. We still see type I and type II error.

    If there is no significant effect we expect to see type I error 5% of the time, if our critical p-value is 0.05. Therefore, our expected type I error rate is 0.05, our simulated rate was 0.06

    When the alternative hypothesis is true, the probability of correctly rejecting the null hypothesis is called the power of the test. The type II error rate is therefore \(1-power\). Here, our simulations give us an estimate of the type II error rate directly - 0.13

    8 - Conclusion

    This data is strongly right-skewed, as we can see in the distribution plots. The Q-Q plot also demonstrates that the data is not normally distributed.

    Nevertheless, the type I and type II error rates here were very similar to those obtained with normally distributed data and the p-value histograms look as expected. The t-test is therefore robust to this violation of the normality assumption in this example.

    This is partly because all of the groups are skewed in the same way - the t-test is generally more robust when the groups have similarly shaped distributions than when the distributions differ substantially between groups.

    8 - Conclusion

    When the groups have both unequal variances and unequal sample sizes, the diagnostic plots show the difference in variance, but may not look dramatically worse than when the sample sizes were equal.

    However, the p-values produced when the null hypothesis is true are no longer uniformly distributed. Instead of the approximately flat distribution seen in the previous examples, the p-value distribution is curved, with relatively few very small p-values. The type I error rate is therefore lower than the expected 5%. In this example, the t-test has become too conservative: it rejects the null hypothesis less often than it should.

    Importantly, unequal sample sizes and unequal variances interact. Neither caused a major problem on its own in our previous examples, but together they can make the standard t-test unreliable.

    This also demonstrates why diagnostic plots should not be treated as a simple pass/fail test: the plots do not necessarily look dramatically different even though the behaviour of the statistical test has changed.

    This shows that even with our relatively small sample sizes, the t-test is robust to some violations of its assumptions - at least in these very controlled simulations where only one assumption is violated at a time. We have also demonstrated that the diagnostic plots are useful but they are not definitive - sometimes the test performs well even if they look quite questionable.
