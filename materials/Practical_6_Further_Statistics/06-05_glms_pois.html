    Poisson GLMs

    Core

    ↑ top

    A binomial GLM is appropriate when the response variable represents one of two possible outcomes. A Poisson GLM can be used to model count data when a Poisson distribution (Comparing real, simulated and expected data - discrete distributions) is appropriate. In a Poisson GLM, we model how \(\lambda\), the expected count, changes with our explanatory variables.

    As with the binomial GLM, the model coefficients are estimated using maximum likelihood. The likelihood is now calculated using the Poisson rather than the binomial distribution, but the principle is the same: R finds the combination of parameter values that makes the observed data most likely.

    Note: Although Poisson GLMs are used for count data, not every count response is adequately described by a Poisson model. We will discuss this below in Assumptions of Poisson GLMs.

    Log-link function

    Core

    ↑ top

    By default, a Poisson GLM uses a log link function, which models the logarithm of the expected count, \(\lambda\), as a linear function of the explanatory variables, with \(\beta_0\) as the intercept and \(\beta_1\) as the coefficient for the explanatory variable.

    \[ \log(\lambda) = \beta_0 + \beta_1 x \] The inverse of this is:

    \[ \lambda = e^{\beta_0 + \beta_1 x} \] This transformation ensures that the expected count is always positive, even though the linear predictor can take any value.

    Fitting Poisson GLMs in R

    Core

    ↑ top

    Let’s use a Poisson GLM to test the following hypotheses:

    • Null hypothesis: There is no association between the number of non-Apidae insect species and the expected number of Apidae species found at a site.

    • Alternative hypothesis: There is an association between the number of non-Apidae insect species and the expected number of Apidae species found at a site.

    First we need to read our data, and add a column containing the number of non-Apidae species at each site.

    site_metadata <- read_csv("data/site_metadata.csv")
site_metadata <- site_metadata |>
  mutate(n_non_apidae = n_unique - n_apidae)

    Now we are ready to fit the GLM. This is very similar to fitting a binomial GLM, except we use the argument family = poisson for the Poisson model.

    • family = poisson to fit a Poisson GLM

    The Poisson GLM uses a log link, so the coefficients represent changes in the log of the expected count. We can exponentiate the coefficient to make it easier to interpret:

    print (exp(coef(glm_apidae)["n_non_apidae"]))

  geom_smooth(
    method = "glm",
    method.args = list(family = poisson)

    Assumptions of Poisson GLMs

    Core

    ↑ top

    As well as the assumptions we discussed in Assumptions, for Poisson GLMs, we additionally assume that:

    • The response is compatible with a Poisson distribution (see Part 3: Using simulation to understand data).
    • The variance of the response, conditional on the explanatory variables, is equal to its mean.

    The relationship between the variance of the response and the mean can be calculated from our model.

    Two statistics are commonly used:

    Pearson dispersion

    \[ \hat{\phi}_{P} = \frac{\sum_{i=1}^{n} r_{P,i}^{2}} {n-p} \]

    where \(r_{P,i}\) is the Pearson residual for observation \(i\), \(n\) is the number of observations and \(p\) is the number of model parameters.

    We can extract the residuals directly from the fitted GLM using the residuals() function with the argument type = "pearson".

    resid <- residuals(glm_apidae, type = "pearson")

    The sum of the squares of these values is \({\sum_{i=1}^{n} r_{P,i}^{2}}\).

    \((n - p)\) is the residual degrees of freedom, which we can also access from the model, as e.g. glm_apidae$df.residual.

    ExerciseExercise 3 - Calculating Pearson dispersion

    Core

    In your glms.qmd Quarto file, write a function named pearson_dispersion to calculate the Pearson dispersion of a GLM, where the input is the fitted GLM and the output is the Pearson dispersion. Apply it to your fitted Apidae GLM.

    AnswerAnswer 
    pearson_dispersion <- function(fitted_glm){
  resid <- residuals(fitted_glm, type = "pearson")
  ss <- sum(resid ^ 2)
  df <- fitted_glm$df.residual
  disp <- ss / df
  return (disp)
}
p_disp_apidae <- pearson_dispersion(glm_apidae)
print (p_disp_apidae)
    [1] 1.347039

    Deviance dispersion

    \[ \hat{\phi}_{D} = \frac{D} {n-p} \]

    where \(D\) is the residual deviance, \(n\) is the number of observations and \(p\) is the number of model parameters.

    The residual deviance is a measure of how much mismatch remains between the observed data and the fitted GLM.

    It’s based on likelihood, comparing the fitted model with a hypothetical saturated model — a model with enough parameters to fit the observations perfectly. We will come back to this later when we compare models.

    We can access the residual deviance using e.g. glm_apidae$deviance.

    As we know, \(n - p\) is the residual degrees of freedom.

    ExerciseExercise 4 - Calculating deviance dispersion

    Core

    In your glms.qmd Quarto file, write a function named deviance_dispersion to calculate the deviance dispersion of a GLM, where the input is the fitted GLM and the output is the deviance dispersion. Apply it to your fitted Apidae GLM.

    AnswerAnswer 
    deviance_dispersion <- function(fitted_glm){
  devi <- fitted_glm$deviance
  df <- fitted_glm$df.residual
  disp <- devi / df
  return (disp)
}
d_disp_apidae <- deviance_dispersion(glm_apidae)
print (d_disp_apidae)
    [1] 1.67018

    In general, we want both of these statistics to be close to 1. Values substantially greater than 1 can indicate overdispersion - the variance in the data is greater than the model expects. Values substantially less than 1 can indicate underdispersion - the variance in the data is less than the model expects.

    Visualising overdispersion

    Extension

    ↑ top

    Accounting for overdispersion

    One way to account for overdispersion is to use a quasi-Poisson model. A standard Poisson model assumes:

    \[ \operatorname{Var}(Y) = \mu \]

    A quasi-Poisson model introduces an additional dispersion parameter, \(\phi\):

    \[ \operatorname{Var}(Y) = \phi\mu \]

    When \(\phi > 1\), this allows the variance to be greater than the mean.

    In R, we can fit this model by replacing family = poisson with family = quasipoisson.

    glm_unique_spp_quasi <- glm(
  n_unique ~ n_unique_flowers,
  family = quasipoisson,
  data = site_metadata
)

summary(glm_unique_spp_quasi)

    ExerciseExercise 7 - Examining quasi-Poisson output

    Extension

    Compare the output from the Poisson and quasi-Poisson models.

    • What has happened to the coefficient estimates?
    • What has happened to their standard errors?
    • What has happened to the p-value for n_unique_flowers?
    • Has accounting for overdispersion changed your conclusion about the association between flower and insect species richness?
    AnswerAnswer
    • The coefficient estimates are identical, but their standard errors are larger in the quasi-Poisson model. The quasi-Poisson model accounts for the additional variation in the data, and therefore gives us less certainty about the estimated coefficients.
    • The p-value for n_unique_flowers has increased from <2 × 10-16 to 6.5 × 10-5, although there is still strong evidence of an association between flower and insect species richness.

    This does not change our conclusion, but accounting for the overdispersion gives us a more appropriate estimate of the uncertainty around the coefficients.

    Review

    ↑ top

    NoteSummary
    • A Poisson GLM can be used to model count data when a Poisson distribution is appropriate.
    • A Poisson GLM models how the expected count, \(\lambda\), changes with one or more explanatory variables.
    • By default, a Poisson GLM uses a log link function, ensuring that predicted expected counts are always positive.
    • Poisson GLM coefficients represent changes in the log of the expected count. Exponentiating a coefficient gives the factor by which the expected count is multiplied for a one-unit increase in the explanatory variable.
    • We can use a fitted Poisson GLM to predict expected counts for new values of the explanatory variables.
    • A Poisson model assumes that the conditional variance of the response is equal to its conditional mean.
    • Pearson dispersion and deviance dispersion can be used to assess whether the variation in the data is consistent with that expected under a Poisson model.
    • Dispersion substantially greater than 1 indicates overdispersion, while dispersion substantially less than 1 indicates underdispersion.

    Programming

    • We can fit a Poisson GLM using glm() with family = poisson.
    • We can use predict() with type = "response" to obtain predicted expected counts on the response scale.
    • We can extract Pearson residuals from a fitted GLM using residuals() with type = "pearson".
    • Components of a fitted model, such as its residual degrees of freedom and deviance, can be accessed using $.
