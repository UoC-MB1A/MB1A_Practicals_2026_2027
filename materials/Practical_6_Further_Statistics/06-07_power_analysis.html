    Power Analysis

    Extension

    ↑ top

    Before collecting data, we need to consider whether our experiment will have enough observations to detect an effect if one really exists. The statistical power of a hypothesis test is the probability that it will correctly reject the null hypothesis when a real effect of a specified size exists.

    It is affected by:

    • Effect size
    • Sample size
    • Sample variation
    • Significance level

    We therefore need to decide:

    • Our desired power - 80% is a commonly used target - the percentage of effects with this effect size that we can detect.
    • A significance level - 5% is often used.
    • Our desired effect size.

    Power analysis functions all operate under the assumption that the data you will collect will meet all of the assumptions of your chosen statistical test perfectly.

    Power analysis should be carried out early, before we perform our data collection. We are learning about it late in the practical not because you do it last, but because it’s helpful to understand the various hypothesis tests first.

    For simple standard tests, R provides analytical power functions. For more complicated models, power can be estimated by simulation.

    Effect size

    Extension

    ↑ top

    Effect size is tricky - it requires us to know, before an experiment is carried out, how big an effect we would consider to be of interest.

    We can get the desired effect size from pilot data, from the literature, or using the following rules of thumb devised by a statistician, Jacob Cohen, as follows:

    Test Small Medium Large
    t-tests 0.2 0.5 0.8
    ANOVA 0.1 0.25 0.4
    Linear models 0.02 0.15 0.35
    Chi-squared 0.1 0.3 0.5

    We should use empirical effect sizes (based on pilot data or the literature) where possible.

    T-test power analysis

    Extension

    ↑ top

    Let’s say that we are designing a study to determine if people diagnosed with lung adenocarcinoma differ in age from people diagnosed with lung squamous cell carcinoma.

    We have identified data from The Cancer Genome Atlas (TCGA) to use as test data to help us design our new study. TCGA is a real cancer genomics research project which collected and analysed thousands of matched pairs of tumour and normal tissue samples from the same individuals, across 33 types of cancer. The samples were compared in terms of their genome, transcriptome, epigenome and proteome.

    For the purpose of designing our study, we only want to look at data showing the age of participants diagnosed with lung adenocarcinoma and lung squamous cell carcinoma.

    You have been provided with a CSV file with the following columns:

    • Patient_ID: A unique ID for each patient.
    • Cancer_Type: The type of cancer they were diagnosed with.
    • Cancer_category: A broader category of where in the body their cancer was diagnosed.
    • N_Severe_Mutations: Total number of severe mutations in any gene identified in this individual.
    • N_Severe_Driver_Mutations: Total number of severe mutations in cancer driver genes identified in this individual.
    • Age: Age in years.
    • Sex: Sex, male or female.
    • Tumour_Stage: Stage of the tumour at the time of the study.
    • Genetic_Ancestry: broad categorisation of genetic ancestry.

    First, let’s read the data frame and filter to include only Lung_Adenocarcinoma and Lung_Squamous_Cell_Carcinoma.

    by_indiv <- read_csv("data/by_individual.csv")
lungs <- by_indiv |>
  filter(Cancer_Type %in% c('Lung_Adenocarcinoma', 'Lung_Squamous_Cell_Carcinoma'))

    Before using these data to estimate a plausible effect size for our new study, we should first establish whether they provide evidence of a difference in age between the two cancer types.

    ttest_lungs <- t.test(Age ~ Cancer_Type, lungs, var.equal=TRUE)
print(ttest_lungs)

    We can calculate the standardised effect size, Cohen’s d, from the data.

    cd <- cohens_d(

    Based on our table above, this is a small effect.

    Now we have this value, we have an idea about what might be a reasonable effect size to see in our own study. We can then calculate the number of participants we would need to have an 80% probability of detecting an effect of this size. We need to use the absolute value of Cohen’s d.

    abs_cd <- abs(cd$Cohens_d)
power_test <- pwr.t.test(
  d = abs_cd,
  sig.level = 0.05,
  power = 0.8,
  type = "two.sample"
)
print (power_test)

    To have 80% power to detect an effect of this size at a significance level of 0.05, we would need at least 323 individuals in each group.

    Anova power analysis

    Power analysis for ANOVA follows a very similar process to for a t-test.

    The differences are:

    • Instead of Cohen’s D, we calculate Cohen’s f using the function cohens_f(). This function runs directly on the fitted ANOVA rather than on the data, so we would do e.g. cf <- cohens_f(anova). We can retrieve the value as e.g. cf$Cohens_f (note the capital C).

    • The power analysis is performed using the function pwr.anova.test(), with four arguments:

      • f - Cohen’s f
      • sig.level - the desired significance level
      • power - the desired power
      • k - the number of groups in the ANOVA

    Simulation-based power analysis

    Extension

    ↑ top

    For more complicated statistical models, there may not be a simple analytical function for calculating power. Instead, we can estimate power using simulation. We repeatedly simulate datasets containing an effect of a specified size, analyse each simulated dataset using our planned statistical test or model, and record whether the effect is detected. The proportion of simulated experiments in which the effect is detected provides an estimate of the power of the proposed study. By repeating this process for different sample sizes, we can estimate the sample size required to achieve our desired power.

    Simulation-based power analysis is particularly useful for more complicated models, including GLMs, where power may depend on several features of the proposed experiment.

    Let’s say we’re planning an experiment to determine if toast will land butter-side-down when dropped. We have two groups of participants, those who consider themselves to be lucky and those who consider themselves to be unlucky. We would consider a difference of 20 percentage points in the probability of the toast landing butter-side-down between these groups to be an effect worth detecting.

    For our power analysis, we will assume that toast dropped by lucky participants has a 40% probability of landing butter-side-down, compared with 60% for unlucky participants.

    We can then determine how many people we would need to recruit to each group using simulation.

    Let’s simulate group sizes of between 5 and 300, with an interval of 20.

    • For each group size, we will run 1000 simulations, in which we generate two random binomial datasets, one with a probability of 0.4 (lucky) of the toast landing butter-side-down and one with a probability of 0.6 (unlucky).
    • We can then compare these groups using a GLM with the model toast_bsd ~ luck, where toast_bsd is 1 when the toast landed butter-side-down and 0 when it landed butter-side-up, and luck is 1 for lucky and 0 for unlucky.
    • We can extract our p-value from the model using summary(model)$coefficients[2, 4] and determine if this is less than our significance threshold of 0.05.
    • The smallest group size for which the estimated power reaches at least 80% is our estimated required sample size.
    # Vector to store the percentages for all groups sizes
perc_vec <- c()

# Try each group size from 5 to 300 with interval 20
for (group_size in seq(5, 300, 20)){
  # Vector to store the results for this group size
  sig_vec <- c()
  # Simulate 1000 times
  for (j in seq_len(1000)){
    # Lucky with 0.4 BSD probability
    lucky <- rbinom(group_size, 1, prob = 0.4)
    # Unlucky with 0.6 BSD probability
    unlucky <- rbinom(group_size, 1, prob=0.6)
    # Put each into a data frame
    df_lucky <- tibble(luck = 1,
                       toast_bsd = lucky)
    df_unlucky <- tibble(luck = 0,
                         toast_bsd = unlucky)
    # Combine the data frames
    df_comb <- bind_rows(df_lucky, df_unlucky)
    # Fit the GLM
    model <- glm(toast_bsd ~ luck,
                 family = binomial,
                 data = df_comb)
    # Extract the p-value
    pval <- summary(model)$coefficients[2, 4]
    # Check if it is significant
    is_sig <- pval <= 0.05
    # Add TRUE or FALSE to the vector
    sig_vec <- c(sig_vec, is_sig)
  }
  # Calculate the percentage of significant p-values
  perc <- sum(sig_vec) / 1000
  # Add it to the vector
  perc_vec <- c(perc_vec, perc)
}

    Fixed sample sizes

    Bonus

    ↑ top

    In the example above, we started with an effect that we wanted to be able to detect and used power analysis to determine the sample size that we would need.

    However, in real experiments there may be practical limits on the number of observations that we can collect. In this case, we can instead use power analysis to investigate how large an effect we would be able to reliably detect with the sample size available to us.

    Imagine that we can recruit a maximum of 100 lucky and 100 unlucky participants for our toast-dropping experiment. We will continue to assume that toast dropped by lucky participants has a 0.4 probability of landing butter-side-down.

    Create a sequence of probabilities between 0.4 and 0.8, with an interval of 0.02. These will represent different possible probabilities of toast landing butter-side-down for the unlucky group.

    probs <- seq(0.4, 0.8, 0.02)

    For each probability, simulate the experiment 1000 times and calculate the proportion of experiments in which the GLM detects a significant effect at a significance level of 0.05.

for (prob in probs){

  sig_vec <- c()

  for (j in seq_len(1000)){

    unlucky <- rbinom(100, 1, prob=prob)

    df_lucky <- tibble(luck = 1,
                       toast_bsd = lucky)
    df_unlucky <- tibble(luck = 0,
                         toast_bsd = unlucky)

    df_comb <- bind_rows(df_lucky, df_unlucky)

    is_sig <- pval <= 0.05
    # Add TRUE or FALSE to the vector
    sig_vec <- c(sig_vec, is_sig)
  }
  # Calculate the percentage of significant p-values
  perc <- sum(sig_vec) / 1000
  # Add it to the vector
  perc_vec_fixed_sample <- c(perc_vec_fixed_sample, perc)
}

    What happens when there is no difference between the two groups? Why is the proportion of significant results close to 0.05?

    When there is no real difference between the groups, the null hypothesis is true. Under the null hypothesis, p-values are uniformly distributed, so approximately 5% will be below our significance threshold of 0.05.

    Review

    ↑ top

    NoteSummary
    • Statistical power is the probability that a hypothesis test will correctly reject the null hypothesis when an effect of a specified size exists.
    • Power depends on the effect size, sample size, variation in the data and significance level.
    • Effect sizes describe the magnitude of an effect independently of sample size. Different statistical tests use different standardised measures of effect size.
    • Power analysis can be used before collecting data to estimate the sample size required to detect an effect of interest with a specified level of power.
    • If sample size is constrained, power analysis can instead be used to determine how large an effect the proposed experiment could reliably detect.
    • Analytical power calculations are available for many standard statistical tests.
    • For more complicated models, power can be estimated by repeatedly simulating the proposed experiment and calculating the proportion of simulations in which the effect is detected.
    • Power analysis depends on assumptions about the expected effect and data, so its results are only as appropriate as those assumptions.
